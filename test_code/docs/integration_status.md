# ChemCritic 本地集成 v0.2

## 当前交付

- 根据2026-10-19团队案例工作簿，生成7条结果记录、5篇独立DOI论文的结构化库。
- SM-001的66% GC与40%分离收率分开存；SM-004 entry 1与entry 7同属一个DOI。
- 团队库按完整底物对精确匹配，支持少量明确的中文/英文名称别名。不是结构搜索、广域文献搜索或SciencePal实时检索。
- 每条结果保留原工作簿行、单元格定位、报告的A级证据声明和本地未独立核验标志。不会把团队声明写成工程端独立核验。
- 每条先例展示底物、目标产物、催化剂、载量、碱、溶剂、温度、时间、气氛、配体和结果口径的相同/不同/未知。名称一致不代表化学体系等价，未知不记为不匹配。
- core-0.2.1新增最多3项优先核查行动。由输入证据缺口触发，列出核查依据、材料、补齐后的判断范围及限制；相关文献只作为字段参照，不作为失败原因的证明。不替用户进行谱图审核或提出反应优化处方。
- B v0.2已明确关闭MVP数值比较；本工程持续执行该限制，未实现排序评分。
- 仅集成B v0.2无争议的S3分支：结构证据缺失或矛盾时为evidence_gap，结果本身完全缺失时为input_gap。S3证据不足时不输出数值目标结论。
- 其余保留分维度目标比较；不将用户自述结构匹配自动提升为已审核产物确认。
- 历史快照仍保留原规则版本，不批量改写旧记录。重评时才应用新规则。
