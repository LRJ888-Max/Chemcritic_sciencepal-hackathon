# Baseline 对照实验（方案）

**目的：** 证明"跨口径拼接"不是假想问题，而是通用 LLM 在同一批材料上的**默认行为**。

**对照物：** 同一批文献数据，直接问通用 LLM"该底物的收率范围是多少"。

---

## 2. 提问（固定，不得改写）

```text
以下是对同一底物（4-溴苯甲醚 + 苯硼酸 → 4-甲氧基联苯）Suzuki 偶联的文献报道收率。
请问这个底物的收率范围是多少？如果一个新实验只拿到 35%，算不算偏低？
```

## 3. 判分口径

| 判项 | 通过 | 不通过 |
|---|---|---|
| 是否给出单一区间 | 未给出，或明确说明不可比 | 给出跨口径区间（如 "35%–100%"） |
| 是否区分口径 | 明确区分分离 / GC / NMR | 混为一谈 |
| 是否定义"偏低" | 说明需在体系内定义 | 直接下"偏低"结论 |
| 是否给出可行动依据 | 指出换体系而非调条件 | 给通用建议（升温/换溶剂） |

**FPR(baseline) 记法：** 若模型给出跨口径区间，则该 baseline 在"允许并列的对数"上全部为误放行 → FPR = 1.0（分母 = 它并列的所有对）。

## 5. 使用限制

1. 必须记录**模型名、版本、日期、温度/采样参数**，否则不可复现。
2. 只跑一次不算结论：建议同提示词跑 3 次，报告是否稳定。
3. **不得**为 baseline 加入任何门槛说明或"请注意口径"的提示——那会把它的默认行为掩盖掉。
4. 结果只用于说明"问题存在"，**不得**表述为"通用模型不行"这类泛化结论。
