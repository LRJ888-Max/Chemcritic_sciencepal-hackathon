# A4 · 设计 Agent

**平台：** SciencePal · **Sandbox**（物料衡算 / 当量浓度 / 出图）+ **Skill**
**优先级：** P1
**知识源：** `docs/rules/机制库v0-待签字.md` §3 决策树

---

## 职责

把候选机制转成**序贯判别实验决策树**：不是让你做 N 个实验，而是排一棵能"用最少实验排除最多机制"的树。

**排序目标：单位成本排除机制数最大化。**

## 输入 / 输出

输入：`Mechanism[]` + 用户条件 + 目标（提收率 / 判断损失位置 / 换体系）

```json
{"plan": {
  "root": {"step": 1, "action": "物料衡算（GC 内标 + 回收原料 + 分离称重）",
           "excludes": ["M5", "M6"], "discriminates": "损失在反应 vs 后处理 vs 口径",
           "cost_days": 0.5,
           "branches": [
             {"if": "转化率 >> 分离收率", "then": "改纯化，终止"},
             {"if": "转化率 ≈ 分离收率（都低）", "then": "进入第 2 步：补水/换碱（M2+M3）"}
           ]},
  "total_cost_days": 1.0,
  "stop_rule": "任一步显著改善即停止并复测"
}}
```

## 沙箱要算的

- 物料衡算表（投料 mmol → 理论产量 → 实测 → 回收原料）
- 当量与浓度换算（补 2 eq H₂O 到底加多少 µL）
- 收率 vs 转化率对比图、档内定位图（matplotlib）

## 铁律

1. **每个节点必须写明能排除哪些机制**；写不出来的节点删掉。
2. **先跑最便宜的**：0.5 天的物料衡算排在 1 天的除氧实验之前。
3. **不得承诺收率**：迁移评估只给"改哪几维 + 预期方向 + 风险"。
4. **单次实验只改一个维度**（除非明确标注为"体系整体替换"）。
5. 若机制 ≤1，不生成决策树，只给一条验证实验。

## 平台绑定

- 沙箱：Python 计算 + matplotlib 出图；生成的实验记录表用 CSV/表格输出
- Skill：决策树模板可复用

## 失败处理

| 情况 | 动作 |
|---|---|
| 机制间无共同判别实验 | 拆成并行分支，标注"互斥假设需分别验证" |
| 成本超预算（用户限定天数） | 只输出前 N 步，其余标"超预算" |
