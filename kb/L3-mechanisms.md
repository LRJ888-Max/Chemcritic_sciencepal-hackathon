# L3 · 机制库（候选原因 + 判别实验）

> **用途：** 当用户的收率低于同档参照时，列出**可被一次实验区分**的候选机制。
> **铁律：** 每条机制是**候选解释**，不是诊断。只说"值得优先排查"，不说"原因就是它"。
> **入库条件：** 必须能在一次实验内被支持或排除。无文献支撑的标 `speculative`，不得排进前两位。
> **适用范围：** Suzuki–Miyaura，芳基溴 + 芳基硼酸。不适用于其它反应类别。

---

## 排序原则（先看这条，再看九条）

> **单位成本排除机制数最大化。** 先跑能一次切开最多机制的那个实验。

```text
优先级 1：物料衡算 / 口径确认   —— 一次区分"反应差 / 后处理差 / 口径错"三类
优先级 2：介质类（碱、水、溶剂）—— 最便宜、影响最大
优先级 3：试剂与催化剂状态      —— 除氧、批次、硼酸品质
优先级 4：副反应与配体          —— 需要分析手段，成本最高
```

## M5 · 后处理 / 纯化损失

- **化学理由**：分离收率 = 转化率 × 分离回收率；柱层析损失、乳化、产物水溶都会压低分离收率。
- **何时不适用**：收率本身是 GC/NMR 定量（未做分离）时，此机制不成立。
- **文献支持**：SM-001 同篇 66% GLC vs 40% 分离，**差 26 个百分点**即为直接证据。
- **判别实验**：物料衡算——GC 内标测反应液转化率，同时回收未反应芳基溴，另取一份做分离称重。
- **观测**：转化率 − 分离收率 = 分离损失。
- **支持则**：转化率高 → 优先改纯化，不改反应条件。**排除则**：两者接近 → 损失在反应阶段。
- **成本**：0.5 天。

## M6 · 收率口径错配

- **化学理由**："35%" 若来自粗品称重或未校准的 NMR 估算，与分离收率不是同一个量。
- **何时不适用**：用户已提供内标与分离记录。
- **文献支持**：SM-004 表列名写 `Yield (%)`、脚注却写 `total conversion ... based on GC`，即典型口径歧义。
- **判别实验**：同 M5，用内标法定量并与分离称重对照。
- **支持则**：差值 >15 个百分点 → 先统一口径，再谈优化。**排除则**：两口径一致。
- **成本**：0.5 天（与 M5 同一实验）。

## M3 · 体系缺水

- **化学理由**：苯硼酸需经氢氧根水解生成四配位硼酸根中间体才能高效转金属化；无水介质显著减慢该步。
- **何时不适用**：体系已含水（醇水、水相、含水 THF）。
- **文献支持**：**P24（RSC Adv. 2021, Table 1）同表溶剂对照**——H₂O–EtOH (1:1) **98%**、纯水 **8%**、异丙醇 **0%**、**THF 0%**。这是"介质决定有没有反应"最直接的一条（¹H NMR 未校准，仅用于趋势）。
- **判别实验**：加 5% v/v 水，或改 DME:H₂O = 4:1 重跑。
- **支持则**：提升明显 → 体系缺水。**排除则**：无变化。
- **成本**：0.5 天。

## M2 · 碱不足 / 碱不溶

- **化学理由**：碱促进硼酸生成 boronate 中间体并加速转金属化；Na₂CO₃ 在无水 THF 中溶解度极低，有效碱浓度可能远低于投料。
- **何时不适用**：体系含大量水，或使用可溶有机碱/醇盐。
- **文献支持**：经典体系普遍用 2–3 eq 碳酸盐 + 含水溶剂；SM-001 用 Na₂CO₃ 2 eq 且苯回流（含微量水）。
- **判别实验**：补 2 eq H₂O 或改用 K₂CO₃ / K₃PO₄ 重跑；记录碱的溶解状态。
- **支持则**：提升 >10 个百分点。**排除则**：无变化。
- **成本**：0.5 天。

## M1 · 催化剂失活 / 载量不足

- **化学理由**：Pd(PPh₃)₄ 对氧敏感，未除氧或储存不当会部分氧化并聚集失活；载量偏低会直接压低转化。
- **何时不适用**：使用高稳定性预催化剂或负载催化剂。
- **文献支持**：**P11（RSC Adv. 2026, Table 1）同底物载量梯度**——0.035 mol% → 15%、0.07 → 50%、**0.1 → 96%**；同表用不含 CQD 的载体对照仅 **3%**（GC 未校准，仅用于趋势）。
- **判别实验**：除氧（冻融/鼓 N₂ 30 min）后重跑；或换新鲜批次并把载量加倍。
- **观测**：收率变化 + 反应液是否变黑（Pd 黑）。
- **支持则**：显著提升。**排除则**：无变化。
- **成本**：0.5–1 天。

## M9 · 试剂状态（硼酸品质 / 芳基溴纯度）

- **化学理由**：苯硼酸易氧化、易脱水成酐，实际当量低于称量值；芳基溴含水或含同系物同样压低收率。
- **何时不适用**：试剂为新开封且记录批号。
- **文献支持**：（暂无原文数据，标 `speculative`）
- **判别实验**：换新批次/重结晶硼酸，或改用硼酸酯；核对芳基溴的 GC/NMR 纯度。
- **支持则**：提升。**排除则**：无变化。
- **成本**：0.5 天。

## M7 · 竞争副反应

- **化学理由**：芳基溴可脱卤（→ 苯甲醚）、同偶联、硼酸自偶联/氧化（→ 联苯）。
- **何时不适用**：物料衡算已闭合（各产物加和 ≈ 100%）。
- **文献支持**：（暂无原文数据，标 `speculative`）
- **判别实验**：粗品 HPLC / LC-MS / ¹H NMR 定性定量副产物。
- **支持则**：副产物占比 >20% → 需抑制副反应。**排除则**：<5%。
- **成本**：0.5–1 天。

## M4 · 温度不足

- **化学理由**：温度低则氧化加成或还原消除慢，可能成为限速步。
- **何时不适用**：已用高活性催化剂（可在室温完成）。
- **文献支持**：**P11 同底物温度梯度**——25 °C **20%**、50 °C **60%**、60 °C **96%**（同载量同时间）。
  **反向证据**：SM-003 在 THF/60 °C 已达 95%（¹H NMR）——说明**温度敏感性随体系而变**。
- **判别实验**：升到 80 °C 或回流重跑。
- **支持则**：明显提升 → 动力学受限。**排除则**：无变化。
- **成本**：0.5 天。
- **备注**：**优先级降到第 4 档**——因为 P11 与 SM-003 都显示 60 °C 可能已经够。

## M8 · Pd : 配体比失衡 / 配体氧化

- **化学理由**：膦配体过量抑制配体解离、不足则活性 Pd(0) 不稳定；P:Pd 比偏离最优显著降活。
- **何时不适用**：使用 Pd(PPh₃)₄ 等配体已内置的预催化剂且未额外加配体。
- **文献支持**：（暂无原文数据，标 `speculative`）
- **判别实验**：P:Pd 由 2:1 调至 4:1 重跑；或"额外补 2 eq PPh₃"与"不补"对照。
- **支持则**：提升。**排除则**：无变化。
- **成本**：1 天。

## 序贯决策树（输出用）

```text
第 1 步：物料衡算（M5 + M6，一次实验，0.5 天）
  ├ 转化率 >> 分离收率 → 损失在分离 → 改纯化，结束
  ├ 转化率 ≈ 分离收率（都低）→ 进第 2 步
  └ 口径无法统一 → 先补内标定量，结束

第 2 步：补水 / 换碱（M3 + M2 合并，0.5 天）
  ├ 提升明显 → 介质问题为主
  └ 无变化 → 进第 3 步

第 3 步：除氧 + 新鲜催化剂（M1，0.5–1 天）｜换新批次试剂（M9，0.5 天）
  ├ 任一有效 → 催化剂/试剂问题
  └ 均无效 → 进第 4 步

第 4 步：副产物谱（M7）｜温度（M4）｜配体比（M8）
  └ 按成本排序，通常先看副产物谱（信息量最大）
```

**注：** 第 3、4 步只在第 1、2 步无法解释时执行——这是"最少实验"原则，也是与"通用建议清单"的核心差异。
