# L3 · 8 维门槛规则（判定依据）

> **用途：** 回答「这条能不能比」。Agent 输出"卡在维度 4"时必须能引用本文件，而不是"模型觉得"。
> **权威版本：** `engine/gates.py`（确定性实现，LLM 不得覆盖）。本文件是可检索的规则原文。
> **版本：** gates v0.4（2026-10-26，含 C 方案）

---

## 一、8 个维度

| # | 维度 | 类型 | 通过条件 |
|---|---|---|---|
| 1 | 底物对一致 | **硬** | 芳基卤 + 硼酸的规范化结构完全一致。**芳基碘 ≠ 芳基溴**（离去基不同即不同底物） |
| 2 | 产物一致 | **硬** | 产物结构一致 |
| 3 | 结果口径 `outcome_type` | **硬** | 两者同类且均非 `unknown`。**禁止任何换算**；`conversion` 不与 `gc` 同框 |
| 4 | Assay 与校准 | **硬**（三层） | 见下节 |
| 5 | 规模 / 当量 / 浓度 | 软 | 规模差 >5 倍 → L1；当量比差 >0.2 → L1；浓度差 >2 倍 → L2；缺失 → L2 |
| 6 | 催化体系 | 软 | 前体不同 → L2；配体不同 → L2；载量差 >2 倍 → L2；mol% 缺失 → L2 |
| 7 | 碱 / 溶剂 / 温度 / 时间 / 气氛 | 软 | 温差 **≥20 °C → L2**；碱不同 → L2；溶剂族不同（含水 vs 非含水）→ L2；时间差 >2 倍 → L1；气氛不同 → L1；碱缺失 → L2 |
| 8 | 后处理与纯化 | 软 | 双方都记录且**明确不同** → L2；仅一方记录 → L1；双方均未记录 → L1 |

## 二、维度 4 的三层验证（核心）

**立场：`outcome_type` 是抽取器给的分类，不是事实。** 字段写 `isolated` 不等于原文真报了分离收率。

### 第一层 · 口径标记必须被原文措辞支撑

| 口径 | `label_raw` 必须含 |
|---|---|
| `isolated` | isolated / 分离 / 称重 / weighed |
| `gc` | gc / glc / 气相 |
| `nmr` | nmr / 核磁 / ¹H |
| `conversion` | conversion / 转化 |

`label_raw` 为空 → `UNKNOWN`（无原文措辞就无法验证口径）。
标记与措辞矛盾（例：标记 isolated，原文只有 "Yield (%)"）→ `UNKNOWN`，需回原文确认。

### 第二层 · 证据等级（仅文献侧）

| 等级 | 含义 | 能否进入比较 |
|---|---|---|
| `A_confirmed` | 已回原文核对（表/entry/脚注） | ✅ |
| `candidate` | 有未决歧义，但已回原文 | ✅（其"未校准"由第三层分级体现） |
| `imported_unchecked` | 从交接表导入，未回原文 | ❌ `UNKNOWN` |

### 第三层 · 定量方法与校准（分级，C 方案）

| 级别 | 条件 | 可比较 | 参与档内定位 |
|---|---|---|---|
| `calibrated` | 分离称重，或有内标（GC 另需定量基准） | ✅ | ✅ |
| `uncalibrated` | **说明了定量方式**但无内标（如 "1H-NMR analysis"、"GC area normalization"） | ✅ 但必须标注 | ❌ **不参与** |
| （阻断） | 连定量方式都没写 | ❌ `UNKNOWN` | — |

**为什么分级而不是一律阻断：** 核过 4 篇开放获取文献，只有 1 篇写了内标（且内标在另一张表的脚注里）。文献普遍不写内标是**行业惯例**，不是造假。一律阻断会让 `gc`/`nmr` 类样本归零。

**但要付代价：** 面积归一化或"产物/原料积分比"得到的百分数，与分离称重**不是同一个量**。它们可以并排展示，但**不能据此下"低于档内水平"的结论**——那正是我们要消灭的假精确。

**依据范围：** 内标与基准**不要求写在被引用那张表的脚注里**。同文的通用实验方法、仪器段、或其它表的脚注都可以作依据，但必须记录 `assay_basis_source`（依据出自哪一句）。

**对两侧要求不同：** 第一、二层只对文献侧执行；用户侧是现场记录者，**追问比阻断更有用**。

## 三、结论计算

```text
任一硬门槛 FAIL      → BLOCKED（确定不可比，优先于"不知道"）
否则任一硬门槛 UNKNOWN → NEEDS_EVIDENCE（去原文确认）
否则                → COMPARABLE（附软维度 L1/L2 标注）
```

| 结论 | 含义 | 必须给出 |
|---|---|---|
| `COMPARABLE` | 可进入同一比较 | 软维度差异与等级；若有未校准，标注 `uncalibrated` |
| `BLOCKED` | 禁止同框 | **阻断维度** + **解锁条件** |
| `NEEDS_EVIDENCE` | 缺关键字段 | **取证清单**（补什么能解锁哪个对比） |

**优先级：** 确定不可比 > 不知道。同时存在时输出 `BLOCKED`。

## 四、常见追问模板（Agent 用）

| 缺什么 | 怎么问 |
|---|---|
| 收率口径 | 「这个 35% 是分离收率，还是 GC/NMR 定量？」 |
| GC/NMR 无内标 | 「有没有内标或定量基准？没有的话我可以按'未校准'展示，但不下结论。」 |
| 碱缺失 | 「碱是什么、几当量？THF 无水体系里 Na₂CO₃ 溶解性差，这一项影响很大。」 |
| 规模/当量缺失 | 「投料多少 mmol、底物当量比是多少？」 |
| 结构证据 | 「NMR 匹配能提供谱图或峰表吗？自述匹配不等于结构已确认。」 |
