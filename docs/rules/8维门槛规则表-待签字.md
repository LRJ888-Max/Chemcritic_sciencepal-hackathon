## 0. 一句话规则

> **硬门槛任一不通过（含 `UNKNOWN`）→ 两个数值禁止同框。**
> **软门槛差异只降证据等级，必须标注，但不阻断。**
> 判定由确定性代码完成，**LLM 无权覆盖**。

## 1. 维度总表

| # | 维度 | 类型 | 通过条件 | 不通过输出 |
|---|---|---|---|---|
| 1 | 底物对一致 | **硬** | 芳基卤 + 硼酸 规范化 SMILES 完全一致 | `BLOCKED:substrate` |
| 2 | 产物一致 | **硬** | 产物规范化 SMILES 完全一致 | `BLOCKED:product` |
| 3 | 结果口径 `outcome_type` | **硬** | 两者同类且均非 `unknown` | `BLOCKED:outcome_type` |
| 4 | Assay 与校准 | **硬** | 按 §2.4 分口径判定 | `BLOCKED:assay` / `UNKNOWN:assay` |
| 5 | 规模 / 当量 / 浓度 | 软 | — | 标注等级 `L1/L2` |
| 6 | 催化体系 | 软 | — | 标注等级 `L1/L2` |
| 7 | 碱 / 溶剂 / 温度 / 时间 / 气氛 | 软 | — | 标注等级 `L1/L2` |
| 8 | 后处理与纯化路径 | 软 | — | 标注等级 `L1` |

**等级定义：** `L1` = 有差异、通常不致命；`L2` = 差异大、足以改变结论，必须在结论旁显式提示。

## 2. 逐维判定细则

### 2.1 维度 1 · 底物对一致（硬）

```text
pass(rec, entry):
    a = canonical(rec.aryl_halide)     # 去盐、去同位素、统一芳香形式
    b = canonical(rec.boronic_acid)
    A = canonical(entry.aryl_halide)
    B = canonical(entry.boronic_acid)
    if any is None: return UNKNOWN
    return set(a,b) == set(A,B)        # 不分方向
```

- **芳基碘 / 芳基氯 / 烯基 / 杂芳基** 一律视为不同底物，不通过。
- 取代基位置不同（邻/间/对）→ 不通过。
- 只在正文写"aryl bromide"而无法对应到具体结构 → `UNKNOWN`。

### 2.2 维度 2 · 产物一致（硬）

同上，比对产物规范化 SMILES。产物未报告 → `UNKNOWN`。

### 2.3 维度 3 · 结果口径（硬）

```text
ALLOWED = {isolated, gc, nmr, conversion}
if rec.outcome_type not in ALLOWED or entry.outcome_type not in ALLOWED: return UNKNOWN
return rec.outcome_type == entry.outcome_type
```

- **禁止任何换算**：不得把 GC 转化率折成"收率"，不得把 NMR 定量当成分离收率。
- **禁止区间拼接**：不得把多个口径的数值合成一个范围。
- 同一篇文献的两种口径（如 SM-001 的 66% GLC 与 40% 分离）是**两个独立值**，不是一个值的两种写法。

### 2.4 维度 4 · Assay 与校准（硬）— 由三层组成

> **关键立场：`outcome_type` 是抽取器给出的分类，不是事实本身。** 一个字段写着 `isolated`，不等于原文真的报了分离收率。所以维度 4 不是"看一眼字段"，而是三层验证。

**第一层 · 口径标记必须被原文措辞支撑**

| 口径 | 原文措辞（`label_raw`）必须含 | 不满足时 |
|---|---|---|
| `isolated` | isolated / 分离 / 称重 / weighed | `UNKNOWN`：标记与原文矛盾，需回原文确认 |
| `gc` | gc / glc / 气相 | 同上 |
| `nmr` | nmr / 核磁 / ¹H | 同上 |
| `conversion` | conversion / 转化 | 同上 |

`label_raw` 为空 → 直接 `UNKNOWN`（没有原文措辞就无法验证口径）。

**第二层 · 证据等级必须达到可比较门槛（仅文献侧）**

| 等级 | 含义 | 能否进入数值比较 |
|---|---|---|
| `A_confirmed` | 已回原文核对（表/entry/脚注） | ✅ 可以 |
| `imported_unchecked` | 从交接表导入，未回原文核对 | ❌ `UNKNOWN`——只能检索展示 |
| `candidate` | 有未决歧义（如 SM-006 校准未注明） | ❌ `UNKNOWN` |

> 这一层是**产品主张的必然结果**：我们比的就是核验过的数。未核验的数一旦放进来，就是在制造我们声称要消灭的假精确。

**第三层 · 定量方法与校准足以支撑该口径**

| 口径 | 通过条件 | 缺失时 |
|---|---|---|
| `isolated` | 无需额外条件（纯化一致性归维度 8，软 L1） | — |
| `gc` | 内标种类 + 定量基准（以卤代物还是硼酸计） | `UNKNOWN`（缺任一） |
| `nmr` | 内标/积分基准 | `UNKNOWN` |
| `conversion` | 内标/外标 + 定量基准（以何物计） | `UNKNOWN`（缺任一） |

> **`conversion` 一行是 2026-10-25 补的**（B 指出：原先第三层没有 conversion 行，而转换率同样需要定量依据，否则无法复算——会造成"假绿灯"）。对应测试 T16。

**对两侧的要求不同：** 第一、二层只对**文献侧**执行。用户侧是现场记录者，对其**追问**比阻断更有用——用户说自己拿到 35% 分离收率，那就是他的记录，不该被"原文措辞"卡住。

> **设计依据与教训：** SM-006 的 92% 是 GC 收率但校准未注明 → 第三层 `UNKNOWN` → 与 SM-004 的 91.9%（hexadecane 内标）**不可同框**。
> 更关键的教训：曾有一版把第一层写成"字段是 isolated 就直接通过"，理由是"字段本身即声明"。这条规则在自家测试数据上全绿，
> 一旦接入队友的案例库——那里的 `assay` 是自由文本、措辞完全不同——**所有分离收率记录立刻被判成"需补证"，产品空转**。
> 结论：**判定必须吃"字段 + 原文措辞 + 证据等级"三者的一致，不能只吃字段。**

### 2.5 维度 5 · 规模 / 当量 / 浓度（软）

| 差异 | 等级 |
|---|---|
| 规模相差 > 5 倍 | `L1` |
| ArX : ArB 当量比相差 > 0.2 | `L1` |
| 浓度相差 > 2 倍 | `L2` |
| 任一字段缺失 | `L2` + 要求补录 |

### 2.6 维度 6 · 催化体系（软）

| 差异 | 等级 |
|---|---|
| Pd 前体不同（Pd(PPh₃)₄ vs Pd(OAc)₂） | `L2` |
| 配体不同或一方无配体 | `L2` |
| mol% 相差 > 2 倍 | `L2` |
| mol% 相差 ≤ 3 倍 | `L1` |
| 缺失 mol% | `L2` + 要求补录 |

### 2.7 维度 7 · 碱 / 溶剂 / 温度 / 时间 / 气氛（软）

| 差异 | 等级 |
|---|---|
| 温度相差 ≥ 20 °C | `L2`（A 于 10/25 收紧：原为 30 °C） |
| 温度相差 < 20 °C | `L1` |
| 碱种类不同（碳酸盐 vs 磷酸盐 vs 醇盐） | `L2` |
| 溶剂族不同（纯有机 vs 含水） | `L2` |
| 时间相差 > 2 倍 | `L1` |
| 气氛不同（空气 vs N₂/Ar） | `L1` |
| 缺失 | `L1`（碱/当量缺失为 `L2`） |

### 2.8 维度 8 · 后处理与纯化（软）

| 差异 | 等级 |
|---|---|
| 双方都记录了纯化方式且**明确不同**（柱层析 vs 蒸馏 vs 重结晶） | `L2`（A 于 10/25 收紧：原为 L1） |
| 仅一方记录（无法判定是否不同） | `L1` |
| 双方均未记录 | `L1` |

> **收紧理由（A 于 2026-10-25 定）：** 柱层析与蒸馏的回收率可差 10 个百分点以上，只标 L1 太轻。但"一方未记录"不等于"方式不同"——不能把信息缺失当成差异。

## 3. 结论计算

```text
def judge(user, entry):
    hard = [g1, g2, g3, g4]
    # FAIL 优先于 UNKNOWN：确定不可比 > 证据不足
    if any(g is FAIL for g in hard):      return BLOCKED(dim=first_fail, unlock=...)
    if any(g is UNKNOWN for g in hard):   return NEEDS_EVIDENCE(dim=first_unknown, unlock=...)
    soft_flags = [g5..g8]
    return COMPARABLE(evidence_grade = degrade(soft_flags))
```

> **优先级说明：** 同时存在 FAIL 与 UNKNOWN 时输出 `BLOCKED`——"已确认不可比"比"暂时不知道"更确定，先告诉用户这条彻底不行，比让他去补证据更省事。

| 结论 | 含义 | 输出要求 |
|---|---|---|
| `COMPARABLE` | 可进入同一 Comparison Block | 必须列出软维度差异与等级 |
| `BLOCKED` | 禁止同框 | 必须给出**阻断维度**与**解锁条件** |
| `NEEDS_EVIDENCE` | 用户侧或文献侧缺关键字段 | 必须给出**取证清单**（补什么能升级） |

**`unlock_condition` 生成规则：** 阻断维度 + 缺的具体字段 + 从哪里能拿到（原文页/表/作者确认/补实验）。

> 原因：这两条记录的 `outcome_type` 是 `unknown`（遵循 10/21 的 D4 决策），而"口径未决"的语义是**取证**而不是**禁止**——告诉用户"去原文确认口径"比直接判死更有用。本文档以实测为准。

**实测状态：** `python engine/run_demo.py` → **16 passed, 0 failed**（2026-10-25）。改动任何规则必须同时更新本节。

> **v0.3 规则变更（重要）：** 维度 4 从"单一检查"改为**三层验证**——①口径标记须被原文措辞 `label_raw` 支撑；②文献侧证据等级须为 `A_confirmed`；③校准信息须足以支撑该口径。

> 新增 T14（标记与原文矛盾）、T15（证据等级不足）锁住这两个漏洞。
