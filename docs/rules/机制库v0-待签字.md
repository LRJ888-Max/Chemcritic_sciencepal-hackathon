## 0. 使用约定

1. 每条机制是**候选解释**，不是诊断结论。对外只可说"值得优先排查"，不可说"这就是原因"。
2. 每条必须能在**一次实验内**被支持或排除，否则不入库。
3. `文献支持` 栏留空即视为 `speculative`，**不得排序进前 2 位**。
4. 机制不是穷举清单：未列出的机制走"未知机制"分支，输出"当前证据不足以列出候选"。

---

## 1. 排序原则（A4 决策树的上游）

> **单位成本排除机制数**最大化。先跑能一次切开最多机制的那个实验。

- 优先级 1：**物料衡算 / 口径确认**（一次区分"反应差 vs 后处理差 vs 口径错"三类，成本最低）
- 优先级 2：**体系性因素**（碱、水、温度）
- 优先级 3：**试剂与催化剂状态**（除氧、批次、硼酸品质）
- 优先级 4：**副反应与配体**（需分析手段，成本最高）

## 2. 九条机制

### M5 · 后处理 / 纯化损失

| 项 | 内容 |
|---|---|
| 化学理由 | 分离收率 = 转化率 × 分离回收率；柱层析损失、乳化、产物水溶性（如含羧基/胺）都会压低分离收率 |
| 何时不适用 | 收率本身是 GC/NMR 定量（未做分离）时，此机制不成立 |
| 文献支持 | 【请你补】SM-001 同篇 66% GLC vs 40% 分离，差 26 个百分点即为直接证据 |
| 判别实验 | **物料衡算**：GC 内标（如十二烷/十六烷）测反应液转化率，同时回收未反应芳基溴，另取一份做分离称重 |
| 观测指标 | 转化率 − 分离收率 = 分离损失 |
| 若支持 | 转化率高 → 优先改纯化，不改反应条件 |
| 若排除 | 转化率与分离收率接近 → 损失在反应阶段，转入 M2/M3/M1 |
| 成本 | 0.5 天 |

### M6 · 收率口径错配

| 项 | 内容 |
|---|---|
| 化学理由 | "35%" 若来自粗品称重或未校准的 NMR 估算，与分离收率不是同一个量 |
| 何时不适用 | 用户已提供内标校准与分离记录 |
| 文献支持 | 【请你补】SM-004 表列名写 "Yield (%)"、脚注却写 "total conversion ... based on GC"，即典型口径歧义 |
| 判别实验 | 同 M5，用内标法定量并与分离称重对照 |
| 观测指标 | 两种口径的差值 |
| 若支持 | 差值 > 15 个百分点 → 先统一口径，再谈优化 |
| 若排除 | 两口径一致 → 数据可信，转 M2/M3 |
| 成本 | 0.5 天（与 M5 同一实验） |

### M2 · 碱不足 / 碱不溶

| 项 | 内容 |
|---|---|
| 化学理由 | 碱促进硼酸生成 boronate 中间体并加速转金属化；Na₂CO₃ 在无水 THF 中溶解度极低，实际有效碱浓度可能远低于投料 |
| 何时不适用 | 体系含大量水（碱已溶解），或使用可溶有机碱/醇盐 |
| 文献支持 | 【请你补】经典体系普遍用 2–3 eq 碳酸盐 + 含水溶剂；SM-001 用 Na₂CO₃ 2 eq 且苯回流（含微量水） |
| 判别实验 | 补 2 eq H₂O 或改用 K₂CO₃ / K₃PO₄ 重跑；同时记录碱的溶解状态 |
| 观测指标 | 收率变化 |
| 若支持 | 提升 > 10 个百分点 → 碱/水体系是主因 |
| 若排除 | 无变化 → 排除 M2，转 M1/M9 |
| 成本 | 0.5 天 |

### M3 · 体系缺水（转金属化受阻）

| 项 | 内容 |
|---|---|
| 化学理由 | 苯硼酸需经氢氧根水解生成四配位硼酸根中间体才能高效转金属化；无水 THF 会显著减慢该步 |
| 何时不适用 | 体系已含水（醇水、水相、含水 THF） |
| 文献支持 | 【请你补】需给出一条"无水 vs 含水"对照的原始数据 |
| 判别实验 | 加 5% v/v 水，或改 DME : H₂O = 4 : 1 重跑 |
| 观测指标 | 收率变化 |
| 若支持 | 提升明显 → 体系缺水 |
| 若排除 | 无变化 → 排除 |
| 成本 | 0.5 天（可与 M2 合并为一次实验） |

### M1 · 催化剂失活 / 未充分活化

| 项 | 内容 |
|---|---|
| 化学理由 | Pd(PPh₃)₄ 对氧敏感，储存不当或未除氧会部分氧化为 Pd(II) 并聚集失活；配体氧化同样降低活性 |
| 何时不适用 | 使用高稳定性预催化剂或负载催化剂 |
| 文献支持 | 【请你补】 |
| 判别实验 | 除氧（冻融/鼓 N₂ 30 min）后重跑；或换新鲜批次并把载量加倍 |
| 观测指标 | 收率变化 + 反应液是否变黑（Pd 黑） |
| 若支持 | 显著提升 → 催化剂/气氛问题 |
| 若排除 | 无变化 → 排除 |
| 成本 | 1 天 |

### M9 · 试剂状态（硼酸品质 / 芳基溴纯度）

| 项 | 内容 |
|---|---|
| 化学理由 | 苯硼酸易氧化、易脱水成酐，实际当量低于称量值；芳基溴含水或含同系物同样压低收率 |
| 何时不适用 | 试剂为新开封且记录批号 |
| 文献支持 | 【请你补】 |
| 判别实验 | 换新批次/重结晶硼酸，或改用硼酸酯（pinacol ester）；核对芳基溴的 GC/NMR 纯度 |
| 观测指标 | 收率变化 + 试剂纯度检测 |
| 若支持 | 提升 → 试剂问题 |
| 若排除 | 无变化 → 排除 |
| 成本 | 0.5 天 |

### M7 · 竞争副反应

| 项 | 内容 |
|---|---|
| 化学理由 | 芳基溴可脱卤（→ 苯甲醚）、同偶联（→ 4,4'-二甲氧基联苯）、硼酸自偶联/氧化（→ 联苯）；碱性含水条件下脱卤与自偶联更明显 |
| 何时不适用 | 物料衡算已闭合（各产物加和 ≈ 100%） |
| 文献支持 | 【请你补】 |
| 判别实验 | 粗品 HPLC / LC-MS / ¹H NMR 定性定量副产物 |
| 观测指标 | 副产物种类与占比 |
| 若支持 | 副产物占比 > 20% → 需要抑制副反应（降碱/降温/调当量） |
| 若排除 | 副产物 < 5% → 排除 |
| 成本 | 0.5–1 天 |

### M4 · 温度不足

| 项 | 内容 |
|---|---|
| 化学理由 | 60 °C / THF 低于经典苯回流（~80 °C），若氧化加成或还原消除慢，则温度是限速因素 |
| 何时不适用 | 已在使用高活性催化剂（可在室温完成） |
| 文献支持 | 【请你补】SM-003 在 THF/60 °C 达到 95%（NMR），说明该温度**本身可行**，因此该机制优先级应下调 |
| 判别实验 | 80 °C 重跑（或回流） |
| 观测指标 | 收率变化 |
| 若支持 | 明显提升 → 动力学受限 |
| 若排除 | 无变化 → 排除 |
| 成本 | 0.5 天 |

### M8 · Pd : 配体比失衡 / 配体氧化

| 项 | 内容 |
|---|---|
| 化学理由 | 膦配体过量会抑制配体解离、不足则活性 Pd(0) 不稳定；P : Pd 比偏离最优值会显著降活 |
| 何时不适用 | 使用 Pd(PPh₃)₄ 等配体已内置的预催化剂，且未额外加配体 |
| 文献支持 | 【请你补】 |
| 判别实验 | 若使用外加配体：P : Pd 由 2:1 调至 4:1 重跑；若为 Pd(PPh₃)₄ 则改为"额外补 2 eq PPh₃"与"不补"对照 |
| 观测指标 | 收率变化 |
| 若支持 | 提升 → 配体比例问题 |
| 若排除 | 无变化 → 排除 |
| 成本 | 1 天 |

## 3. 序贯决策树（A4 生成，示意）

```text
第 1 步：物料衡算（M5 + M6 同一次实验，0.5 天）
   ├─ 转化率 >> 分离收率 → 损失在分离 → 改纯化，结束
   ├─ 转化率 ≈ 分离收率（都低）→ 进入第 2 步
   └─ 口径无法统一 → 先补内标定量，结束

第 2 步：补水 / 换碱（M2 + M3 合并，0.5 天）
   ├─ 提升明显 → 体系因素为主，进一步优化溶剂/碱
   └─ 无变化 → 进入第 3 步

第 3 步：除氧 + 新鲜催化剂（M1，1 天）｜换新批次试剂（M9，0.5 天）
   ├─ 任一有效 → 催化剂/试剂问题
   └─ 均无效 → 进入第 4 步

第 4 步：副产物谱（M7）｜温度（M4）｜配体比（M8）
   └─ 三者按成本排序，通常先看副产物谱（信息量最大）
```

**注：** 第 3、4 步只在第 1、2 步无法解释时执行——这是"最少实验"原则的体现，也是本产品相对"通用建议清单"的核心差异。
