## 1. 为什么需要分档

同一个底物的"收率"在文献里跨 40%–100%，直接给区间就是**假精确**。

分档的作用是把"异常"限定在**有定义域**的范围内：

> **"你的值偏低"这句话，只在同一档内才成立。跨档只能谈"迁移目标"，不能谈"正常区间"。**

没有分档，产品就退化成"拿一个数比一个假区间"。

> **⚠️ 分档只表示体系族不同，不代表优劣。** 档 A 不等于落后，档 B 不等于更好；任何对外表述（Demo、项目说明、报告、答辩）都不得暗示档与档之间存在优劣或先进程度差异。分档的唯一目的是让"异常"有参照，不是给方法排名。

**归类轴（三条，合起来定义"体系族"）：**

1. **活性 Pd 物种的物理形态**——分子配合物 / 原位生成 / 预先制备的纳米颗粒 / 负载固载 / 本体金属
2. **配体族**——膦类 / 非膦类 / 无外加配体
3. **介质**——纯有机 / 含水或醇水 / 无溶剂

**判据为什么不是"条件"：** 温度、溶剂、时间在文献里是跟着催化体系走的，不是独立变量。同一分离口径下 40 / 95 / 100 的跨度，主要由体系解释而不是由条件解释。把条件当判据会把"同体系不同条件"硬拆开，反而破坏参照池。

**可核验的操作判据（"一张表原则"）：**

> 如果原作者会把两个体系放进**同一张横向比较表**直接比数值，它们同档；否则不同档。

这条判据的好处是不靠拍脑袋——回去看原文表格就能验证。

### 为什么是三档

**档数上限由"参照池"决定，不由化学分类的完备性决定。**

现在总共 8 个报告值：分三档 ≈ 2.7 个/档；若按化学直觉分六档（膦 / 亚膦酸 / NHC / pincer / 纳米颗粒 / 负载），每档约 1.3 个值，**给不出档内区间**，"档内定位"立刻变成伪命题。

所以三档是**当前数据能支撑的最大粒度**，是参数不是结论。扩档触发条件见 D5。

## 2. 三档定义

| 档 | 名称 | 判据 | 典型特征 |
|---|---|---|---|
| **A** | 分子膦配体均相 Pd | 分子配合物 + **膦类配体**（含亚膦酸），无固载，有机介质 | 有机溶剂为主；碳酸盐或 NaOtBu；条件接近经典 Suzuki |
| **B** | 无配体 / 水相 Pd | **无外加配体**，Pd 为 Pd(II) 盐（含反应中原位生成的 Pd(0)/NPs），含水介质 | 室温至中温；多为"绿色/水相"路线 |
| **C** | 特化体系 | 负载/固载（MOF、碳、聚合物）、**预先制备的纳米颗粒**、非膦配体（NHC、pincer、氮/硫配体）、无溶剂 | 条件常极端（高温水相、球磨）；结果口径多为 GC |

**判档顺序（严格按此顺序，物理形态优先于配体族，配体族优先于介质）：**

```text
1. support = solid_support                        → C   (R1)
2. medium  = solventless                          → C   (R2)
3. catalyst_form = nanoparticle（预先制备）        → C   (R3)
4. catalyst_form ∈ {supported, bulk_metal}         → C   (R4)
5. ligand_family = non_phosphine                  → C   (R5)
6. ligand_family = none 且 medium = aqueous        → B   (R6)
7. 兜底：分子配合物 + 膦类配体                      → A   (R0)
```

> **优先级理由：** 活性物种是不是"分离相"，比"有没有配体"更能解释收率差异与非均相行为（可回收性、烧结、浸出）。所以 R3（纳米颗粒）压过 R6（无配体水相）。

| SM-004.1 / 004.7 | Pd-bpydc-Ln（MOF 骨架）/ MeOH | R1 + R4 | **C** | 固载 |
| SM-006 | SNS-Pd pincer / K₃PO₄ / H₂O / 140 °C | R5 | **C** | 非膦配体 |

### SM-005 的判定说明（对应 D2）

SM-005 是**多属性冲突的典型**：`nanoparticle`（像 C）+ `ligand_family=none` + `support=none` + `medium=aqueous`（像 B）。

- **主判 C**：预先制备、经表征（TEM/XRD）的生物法 Pd 纳米颗粒，活性位点是**表面 Pd**，属非均相。其行为（可回收性、烧结、浸出）与无配体 Pd 盐不同。
- **备选 B**：操作谱系确实与 B 一致（无配体、水相、室温、短时）。
- 系统输出 `borderline = [B, C]`、`confidence = low`，**并自动做双档敏感性分析**（见 §4.3）。

> **D2 的化学依据（技术侧代签，请 A 复核）：** 判据是"活性物种是不是分离相"，而不是"操作上像不像"。预先制备的纳米颗粒是分离相；PdCl₂ 在反应中原位生成的 Pd(0) 更可能是可溶物种 / 纳米颗粒储库，因此归 B。

## 4. 自动判档机制

> **核心原则：把"档"从人的判断，改造成"字段 → 规则 → 结果"的确定性计算。** 不逐条人工核验，也不让用户自己选档。

### 4.1 受控词表（抽取层只许输出枚举）

| 字段 | 取值 |
|---|---|
| `catalyst_form` | `molecular_complex` / `in_situ_salt` / `nanoparticle` / `supported` / `bulk_metal` |
| `ligand_family` | `phosphine` / `non_phosphine` / `none` |
| `support` | `none` / `solid_support` |
| `medium` | `aqueous` / `organic` / `solventless` |
| `activation_mode` | `thermal` / `mechanochemical` / `microwave` |

抽取 Agent 只填枚举，**不许输出自由文本**。这样"抽错"可以被抽检发现，而"判档"永远可复现。

### 4.2 规则与冲突检测

```python
hits = [r for r in RULES if r.matches(profile)]
if not hits: hits = [FALLBACK]
tiers = {h.tier for h in hits}
primary = min(hits, key=priority)          # 物理形态 > 配体族 > 介质
borderline = sorted(tiers) if len(tiers) > 1 else []
```

**多条规则命中且结论不同 → 强制 `borderline`，禁止"取第一条"静默通过。**

### 4.3 边界不阻断：双档敏感性分析

档只影响"档内定位"这一步，**不影响硬门槛**，所以档的不确定不该让流程卡住：

```text
按 B 算定位 → 参照 {100, 95}
按 C 算定位 → 参照 {95}
两档结论不同 → 输出"档归属敏感" + 请用户补录可观察事实
```

对用户呈现的**不是**"请选择档"，而是：

> "该催化剂是**预先制备的纳米颗粒**，还是**原位生成**的？"

**永远不问"这算哪一档"**（用户答不了），只问可观察的事实：买的还是自己做的、溶液还是球磨、配体是膦还是 NHC。

### 4.4 自动核验（替代逐条人工）

| 机制 | 做法 | 现状 |
|---|---|---|
| 可审计 | 每条记录输出命中 `rule_id` | `python engine/run_demo.py` 屏 4 |
| 冲突不静默 | 多规则结论不同 → 强制 borderline | SM-005 自动识别为 B/C |
| 交叉校验 | 计算值与人工标注比对 | 8/8 一致 |
| 抽样复核 | B 抽 10%（≥5 条）人工判档，一致率 < 90% 改规则 | 待 B 执行 |
| 版本化 | `RULE_VERSION = tier-0.1` 写入输出 | 已实现 |

## 5. 档内可比性：分档 ≠ 自动可比

分档只解决"和谁比"，**不解决"能不能比"**。同档记录仍需通过 8 维门槛（见 `8维门槛规则表-待签字.md`）。

| 情形 | 结论 |
|---|---|
| 同档 + 同口径 + 同校准 | ✅ 可进同一 Comparison Block |
| 同档 + 不同口径（GC vs 分离） | ❌ BLOCKED（维度 3） |
| 跨档 + 同口径 | ⚠️ 可作**迁移目标**，不作"正常区间" |
| 跨档 + 不同口径 | ❌ BLOCKED，且不得作为迁移论证 |

## 7. 已知局限

1. **NHC-Pd 会被归入 C**，但它与膦配体 Pd 的操作谱系几乎相同，可能导致参照池被拆散。缓解：软维度 6 标注"配体族接近膦配体"，并在输出中提示"可参考档 A 的迁移目标"。
2. **同一档内的条件跨度可能很大**（如档 C 从 30 °C 到 140 °C）。档只提供参照池，条件差异由软维度 5–7 承担，不得靠档掩盖。
3. **档 A 目前只有 2 条记录**（SM-001、SM-003），其中分离口径仅 1 条 → 档内区间实质是单点参照，必须在输出中说明"仅 1 条同档参照"。
4. 机械化学、光化学、电化学等活化方式目前仅作为标注，未参与分档——若后续纳入，需重新评估档数。

## 8. 对外表述口径

> **不可以说：** "文献里这个底物能做到 100%，你只有 35%。"
> **可以说：** "你的 35% 属于档 A（经典膦配体体系），该档在此底物上的文献分离收率是 40%；100% 来自档 B（无配体水相），95% 来自档 C（生物法 Pd 纳米颗粒）。"

**必须同时说出的两点：**

1. 分档只表示体系族不同，**不表示优劣**；
2. 档 A 当前只有 1 条同口径参照，属**单点参照**，不是统计区间。
