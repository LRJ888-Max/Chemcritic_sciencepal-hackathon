## 1. 为什么需要分档

同一个底物的"收率"在文献里跨 40%–100%，直接给区间就是**假精确**。

分档的作用是把"异常"限定在**有定义域**的范围内：

> **"你的值偏低"这句话，只在同一档内才成立。跨档只能谈"迁移目标"，不能谈"正常区间"。**

没有分档，产品就退化成"拿一个数比一个假区间"。

## 2. 三档定义

| 档 | 名称 | 判据（按顺序判断） | 典型特征 |
|---|---|---|---|
| **A** | 分子膦配体均相 Pd | 有明确的**膦/亚膦酸配体**，Pd 为**分子前体**（Pd(PPh₃)₄、Pd(OAc)₂+配体、PdCl₂+配体） | 有机溶剂为主；碱多为碳酸盐或 NaOtBu；条件接近经典 Suzuki |
| **B** | 无配体 / 水相 Pd | **无外加配体**，Pd 为 Pd(II) 盐或**原位/生物法 Pd 纳米颗粒**，介质为水或醇水 | 室温至中温；多为"绿色/水相"路线 |
| **C** | 特化体系 | 非膦配体（NHC、pincer、氮配体）或**负载/固载**（MOF、碳、聚合物）或**机械化学/无溶剂** | 条件常极端（高温水相、球磨）；结果口径多为 GC |

**判档顺序（必须按此顺序，避免同一条记录被判进两档）：**

```text
1. 是否负载/固载（MOF、碳、聚合物、氧化物载体）?  → 是 → 档 C
2. 是否存在非膦配体（NHC、pincer、Schiff 碱、氮配体）? → 是 → 档 C
3. 是否无外加配体且介质含水/醇水?                  → 是 → 档 B
4. 其余（有膦配体的分子 Pd 体系）                  → 档 A
```

## 4. 档内可比性：分档 ≠ 自动可比

分档只解决"和谁比"，**不解决"能不能比"**。两档内的记录仍需通过 8 维门槛（见 `8维门槛规则表-待签字.md`）。

| 情形 | 结论 |
|---|---|
| 同档 + 同口径 + 同校准 | ✅ 可进同一 Comparison Block |
| 同档 + 不同口径（GC vs 分离） | ❌ BLOCKED（维度 3） |
| 跨档 + 同口径 | ⚠️ 可作**迁移目标**，不作"正常区间" |
| 跨档 + 不同口径 | ❌ BLOCKED，且不得作为迁移论证 |

## 6. 对外表述口径（写进项目说明与 Demo 旁白）

> **不可以说：** "文献里这个底物能做到 100%，你只有 35%。"
> **可以说：** "你的 35% 属于档 A（经典膦配体体系），该档在此底物上的文献值是 40%；95%–100% 属于档 B，来自完全不同的催化体系。"

**关键差异：** 前者是跨档比较 + 隐含"你失败了"；后者是档内定位 + 指出真正的提升路径（换体系，而不是调条件）。
