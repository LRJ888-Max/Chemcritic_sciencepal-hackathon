## 1. 规则层应该给什么（引擎实跑）

对「同底物 + 同口径（isolated）+ 条件全不同」的参照，用 `gates.judge(USER-A, ref)` 实测：

| 参照证据等级 | 判定 | 阻断维 | 校准 | 条件差异去哪了 |
|---|---|---|---|---|
| `A_confirmed` / `candidate` | **COMPARABLE** | — | calibrated | 全部落 `soft_flags`（L1/L2），**不阻断** |
| `imported_unchecked` | **NEEDS_EVIDENCE** | **assay（D4 第二层）** | calibrated | 同上 |

两条铁的事实：

1. **条件缺失/不同不改变状态**，只记 L1/L2（规模 L2、催化剂体系 L2、碱/温/时间 L2、后处理 L1）。这是 10/19 定的「条件字段缺失不降状态」，也是 HB3 的实现形态。
2. **状态只由 D1–D4 决定**。要判 NEEDS_EVIDENCE，唯一合法理由是文献侧未核验（D4 第二层）；**不能是「碱没记」**。

## 3. 三个硬问题

### ① 归因错误：把软维当硬门槛（最严重）

原文：「这里有大量 UNKNOWN（碱、载量、规模、气氛、当量比）→ NEEDS_EVIDENCE」，并引用「任一硬门槛 UNKNOWN → NEEDS_EVIDENCE」。

**但碱、载量、规模、气氛、当量比全是软维（D5–D8）。** 它用硬门槛的规则解释了软维的缺失，结论对、理由错。后果有两层：

- **指标层**：BDA（维度归因准确率）会判错。产品主张是「说清为什么不能比」，理由错了，主张就空了。
- **产品层**：如果参照其实是已核验的，正确答案是 **COMPARABLE**（见 §1），它却因条件缺失判成 NEEDS_EVIDENCE —— 这是**假阴性，会把能比的样本也挡掉**。反过来，若真是未核验，正确答案的理由应是「文献侧未核验」，它一个字没提。

这一对正好是 FNR 那一侧的实测样本，比 gold set 里任何一对都真实。

### ② 知识库命中 0：演示链没接真值库

它自己说「知识库命中 0，参照均来自公开 web 检索」。这意味着平台 agent 用的**不是** pool30 / 51 行候选，而是现场 web 抓的、未核验的、无 locator 的条目。三个后果：

- M2（来源可打开率）与 M3（引用可定位率）在演示现场会是 **0%**；
- `evidence_grade` 无从谈起，D4 第二层必然 UNKNOWN —— 也就是说它现在的 NEEDS_EVIDENCE **结论碰巧对**，但靠的是「什么都没核」；
- 我 10/25 说的「演示底物档 A 只有 1 条同口径参照」被现场证实：正因为池里没有 4-溴苯甲醚 + isolated 的同框记录，它只能去外面找，而外面找的全是未核验的。

### ③ 表格内部违反 HB2（跨口径并列）

「可比性判定」表把 **95% isolated、79% isolated、"44% 产率"、"高收率"** 放进同一张表横向对照。其中「44% 产率」口径未声明、「高收率」不是数值 —— 这两行按 D3 必须 UNKNOWN，不应出现在数字对照表里。这张表在演示里会被评委盯着看，是最容易被抓的地方。

## 4. 做得对的两件事（要保住）

1. **机制排查结构完全符合设计**：3 个候选机制，每个绑定输入里的具体差异、给出判别实验、按「单位成本排除机制数」排序，最后收敛到 1 个实验。这是差异化卖点，别为了简短砍掉。
2. **诚实自报**：「知识库命中 0」「未在沙箱执行」「规则版本 gates v0.4」—— 前两条符合 M 系列要求，保留。第三条「v0.4」查无出处（规则表表头仍是 `v0.1 · DRAFT`），要么统一版本号，要么不要主动报。

## 5. 修点（按性价比排序）

**给 C（3 条，都在适配层，不动规则）**

1. 判定归因改为**逐维输出 + 硬维优先**：先列 D1–D4 的 PASS/FAIL/UNKNOWN，再列 D5–D8 的 L1/L2；`reason` 只能取硬维。约 0.5 天。
2. **禁止输出差值**：档内定位未开启时，任何「差 N 个百分点」「低于/高于 X%」都要被过滤。包括"虽然不成立但…"这种句式。
3. **引用必须带 locator**：检索结果落成 `{authors, year, journal, doi_or_url, table, entry, footnote}`，缺 DOI/URL 的条目不得进入正文，只能进「待核」列表。

**给 A（1 条，决定演示能不能升级）**

核 **1 条「4-溴苯甲醚 + isolated」的同框参照**（首选现场抓到的那条「乙二醇 / Pd(OAc)₂ / K₃PO₄ / 室温 / 95%」，若开放获取）。核成后池里就有一条 `A_confirmed` 的 isolated 同底物记录，演示可以从「只能说不比」升级为「可以给档内定位（uncalibrated 不参与结论）」，同时 FNR 那一侧有了分母。**这是 10/31 前唯一能真正改变演示叙事的动作。**
