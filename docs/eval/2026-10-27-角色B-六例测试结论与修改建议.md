## 三、提示词层（A 改）

### P1 · 三处强制要求差值，与禁令 1 冲突

**证据：**

```
v3:33   不得判成败…只说"与某文献值相差 X 个百分点"。
v3:111  【结论】写清：你的值、与哪篇文献的哪个值可以并排比较、差多少个百分点；
v3:128  ④ 与同体系可比数据的对照（你的值、可比值、差值、单点参考的限制）
```

**冲突对象：** `kb/L3-gates.md` 禁令 1 ——「不得输出数值差值，除非档内定位已开启；只要出现那个数字，就算违反」。

**改法：**

| 行 | 改为 |
|---|---|
| 33 | 「不得判成败，**也不得输出或复述任何数值差值**。只说『与某文献值处于同一量级／高于／低于』这类定性表述。」 |
| 111 | 「写清：你的值、与哪篇文献的哪个值可以并排比较。**若同档同口径参照 ≥2 条**，给出参照值与区间；**仅 1 条时只并列并列，不给差值**。」 |
| 128 | 删掉「差值」，改成「与同体系可比数据的对照（你的值、可比值、口径是否一致、单点参考的限制）」 |

**为什么必须改：** 现在 T1 里那句「相差 5 个百分点」，是提示词要求它说的。而它自己的数据库里，同档同口径参照只有 1 条（SM-001b 40%），根本不构成区间。规则写对了、提示词写反了。

---

### P2 · 111 与 112 互相矛盾

```
111: …差多少个百分点；
112: 若只有一条可比数据，必须说明"只能作单点参考，不足以建立正常范围"。
```

**现象：** T1 输出里同时出现「相差 5 个百分点」和「只能作单点参考，不足以建立正常范围」——两句自相矛盾。

**这不是模型精神分裂，是它同时执行了两条相反的指令。**

**改法：** 合并为一条——

> 「若同档同口径参照 ≥2 条：给出参照区间，可并列展示，不给差值。
> 若仅 1 条：只并列两个值，明说『单点，不构成范围』，不给任何差值。
> 若 0 条：见检索无命中条款。」

---

### P3 · 第 167 行写死例句，导致示例过拟合

**证据：**

```
v3:167  文献引用格式固定：作者 + 年份 + 期刊卷页 + 表号。例：
        "Miyaura、Yanagi 与 Suzuki（Synth. Commun. 1981, 11, 513，表 II）报道同一底物的分离收率为 40%"
```

**现象：** T1 与 T7（重跑）输出**逐字相同**，都原样复制了这个句子。T7 的输入是残缺的（只说「收了 35%」，没说口径、没说当量、没说纯化），但它仍输出「你的 35% 分离收率」「无水 THF」「柱损失」——**这些输入里根本没有**。

**机制：** 底物一致时，模型把示例当答案模板复用，跳过追问环节。

**改法：**

> 「文献引用格式固定：作者 + 年份 + 期刊卷页 + 表号。
> 例：『作者A、作者B（期刊 年份, 卷, 页，表 X）报道…』
> **示例仅示范格式与引文结构，其中任何作者、数值、条件都不得出现在你的回答里。所有引文与数值必须来自本次检索。**」

同时补一条硬约束：

> 「用户未明确说出收率口径（分离／GC／核磁／转化率）时，**不得替用户指定口径**，一律先按 `未确认` 处理并追问。」

---

### P4 · 术语替换表抹掉关键事实

**证据：**

```
v3:161  NEEDS_EVIDENCE → 收率定义不清，需先确认原文
v3:162  calibrated / uncalibrated → 分离称重定量 / 原文未注明定量依据
```

**现象：** T2 里提问「Molecules 2018 那条 35.0% 能不能跟我比」，真实记录是：

```
locator:   Table 1 entry 1 + footnotes a/c, PDF p.4
label_raw: "Yield (%) — 脚注: total conversion determined from the
            internal standard yield ... based on GC"
note:      表列名与脚注冲突，口径未决
assay:     GC，内标十六烷
```

原文明明写了定量依据（基于 GC、内标十六烷），问题是**表头写 Yield、脚注写 conversion，两处打架**。但模型按第 161/162 行替换，输出成「原文未注明是分离收率、GC 收率还是核磁定量」——**事实说反了**。

这是产品最独特的识别能力（读出「表头与脚注不一致」），被术语替换表抹平成了「文献没写」。

**改法：** 把固定替换词改成「可解释的等价表述」：

> 「对外不使用内部术语，但**不得简化到丢失事实**。
> 口径未决时，必须复述原文两处措辞再说明不一致，例如：
> 『原文表头写 Yield (%)，但脚注写 total conversion … based on GC（内标十六烷），两处定义不一致，因此无法确定 35.0% 是收率还是转化率。』
> 不得只说『原文未注明定量依据』——那与原意不符。」

---

### P5（提示词侧）· 第 164 行禁止 L1/L2，但输出每条都标

```
v3:164  8 维门槛、硬门槛、软维度、L1、L2、D3 → 一律不出现，改说具体化学差异
```

**现象：** T1 输出「碱未记录(L2)」「催化剂不同(L2)」「溶剂族不同(L2)」，三条全违规。

**改法：** 保留禁令，并在【为什么】段落模板里明确写：

> 「【为什么】3 条，每条 ≤20 字，**用化学语言说差异，不得出现 L1/L2/软维字样，也不得用『未记录』作为解释**——缺失只说明『待补』，不是差异原因。」

（后半句同时治了 T1 的另一个毛病：拿软维当因果解释。）

## 四、引擎层（C 改）

### P5 · 跨档仍算差值，违反自身文档

**代码：**

```python
# engine/placement.py:115-117
tier = user.tier
same_tier = [r for r in same_class if r.tier == tier] if tier else []
pool_ref = same_tier or same_class          # ← 同档为空 → 静默回退跨档全池

# engine/placement.py:142-147
"tier_basis": "同档" if same_tier else "同口径（跨档）",   # ← 它知道自己是跨档
"delta_vs_min": round(user.outcome_value - min(values), 1),   # ← 却照样算
"delta_vs_max": round(user.outcome_value - max(values), 1),
```

**同文件第 9 行文档字符串写的是：**

> 「异常只在档内定义；**跨档只输出迁移目标，不输出正常区间**。」

**设计写对了，实现违反了它。**

**改法：**

```python
if tier is None:
    return {"status": "TIER_UNKNOWN",
            "action": "先确认催化体系档位，不做档内定位"}

same_tier = [r for r in same_class if r.tier == tier]
if not same_tier:
    return {"status": "NO_SAME_TIER_REFERENCE",
            "tier": tier,
            "comparables": [r.record_id for r in same_class],
            "action": "跨档参照只能并排展示，不给差值、不给区间"}

# 同档但参照只有 1 条时，同样不给 delta
if len(values) < 2:
    delta_vs_min = delta_vs_max = None
```

**三条原则：** 档位算不出来要报错，不要静默回退；跨档不返回 delta；同档但仅 1 条参照也不返回 delta。

---

### P5b（建议新增）· 用户侧口径无校验

现在 `judge()` 的 D4 第一、二层只对文献侧执行，用户侧传进来什么 `outcome_type` 就信什么。T7 里模型能凭空给出「分离收率」，引擎照单全收。

**建议：** 用户侧 `outcome_type` 必须有 `label_raw` 支撑——用户原话里出现「分离／柱层析／称重」才允许 `isolated`，没有就强制置 `unknown` 并触发追问。

这是最后一道防线：**无论模型怎么补，数字都过不去。**

## 九、两条给以后的提醒

1. **改提示词后，必须回头对一遍 L3-gates 的禁令。** 这次六处冲突，全是「提示词要求」和「知识库禁止」打架，而提示词优先级更高、每次必读，所以永远赢。
2. **示例的危险大于范式的危险。** 第 167 行那句例句，本意是示范引用格式，实际结果是让模型在残缺输入下直接套用整段答案。写示例时，占位符要中性，且必须加一句「示例不得出现在回答里」。
