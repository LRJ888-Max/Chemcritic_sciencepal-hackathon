## 二、但有一个洞被 v8 放大了，必须先修再测

### v8 把「模型自己判断」这条路堵死了

上一轮 T4b（3-溴噻吩 +「跟最好的差多少」）**能通过，是因为模型自己读了 `verdicts` 全 BLOCKED，主动忽略了 `placement`。**

v8 行 193 与行 222 现在写的是：

> · 差值取 `placement.delta_vs_min`（同档且你有实测值时才非 null），**不要自己相减**
> · ★ Z 必须取自 `placement.delta_vs_min`；**为 null 时不许写任何差值**

而引擎对 3-溴噻吩返回的是：

```
verdicts  : ['BLOCKED']            blocking = substrate
placement : status=PLACED  ref=[40, 50, 93, 99]  delta_vs_min = 0     ← 不是 null
```

**0 不是 null。按 v8，模型必须写「差 0 个百分点」。**

| | v5 时代 | v8 时代 |
|---|---|---|
| 引擎给 `delta = 0` | 模型可自行仲裁 verdicts，拒绝比较 | v8 明令照抄 → **必然输出「差 0 个百分点」** |
| 后果 | 侥幸通过（两次对抗问法都没触发） | 必然暴露，且 W18 直接命中 |

**所以 T4/R2 这条素材在修 `placement` 之前不要测。** 测了只会证明一件已知的事，还会浪费一个会话。

### 根因只有一个，位置精确到行

`engine/placement.py:124`：

```python
same_class = [r for r in records if r.outcome_type == user.outcome_type]
```

只按**收率口径**过滤，不看底物对。而同文件第 149–152 行的 `migration_targets` 已经在用现成的 `_same_pair(user, r)` —— **函数就在旁边，只是没用在这里。**

证据是双向污染：

| 用例 | 参照池 | 应为 |
|---|---|---|
| C1 4-溴苯甲醚 | `[40, 50, 93, 99]` | `[40, 50]` |
| C6 4-溴甲苯 | `[40, 50, 93, 99]` | `[93, 99]` |
| C3 3-溴噻吩 | `[40, 50, 93, 99]` · delta=0 | `[]` · null |

三个不同底物拿到**同一个池子**。93/99 是 4-溴甲苯的 P30/P28，40/50 是 4-溴苯甲醚的 SM-001b/P36。

## 三、修法（已在临时副本上验证，9/9 通过）

两个 patch 已放在 `tests/patches/`：

- `placement_2026-10-29.patch`（38 行）— 底物过滤 + 字段补齐
- `gates_2026-10-29.patch`（24 行）— 缺失不写成差异

### 改动 1｜`engine/placement.py:124`

```python
# 改前
same_class = [r for r in records if r.outcome_type == user.outcome_type]

# 改后
same_class = [r for r in records
              if r.outcome_type == user.outcome_type and _same_pair(user, r)]
```

### 改动 2｜`engine/placement.py` 加 `ensure_keys()`

在 `def placement(` 之前插入。原因：`UNDEFINED` 时 `placement` 只有 3 个键（`status/reason/action`），而 v8 把 `reference_values` / `delta_vs_min` 当恒存在字段读。**缺键 ≠ null**，agent 读到 undefined 会以为"没这个字段"，要么崩，要么自己补一个。

### 改动 3｜`engine/gates.py:366` 的 `_soft()`

`气氛不同：None vs n2` 就是这么来的。改成：

```
气氛不同：未记录 vs n2   →   气氛未记录（参照为 n2）
```

⚠️ **不要在 `_soft()` 里 `import re`**。单文件 bundle 是各模块拼接而成，`gates` 段历史上没有 `import re`，我试过加 `re.match`，直接在 `--json` 路径上 `NameError`。用字符串 `split` 处理。
