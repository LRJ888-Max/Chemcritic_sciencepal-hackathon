# 角色B｜平台 Agent 调教与测试手册（会话级测试五例 + 调教循环）

日期：2026-10-27 16:30
用途：给 A/C 调平台 agent 用；也是 10/28 冻结前的回归标准。**每次改动提示词/工具配置后，五个用例全部重跑。**

---

## 一、调教一个平台 agent 的三个杠杆（原理，30 秒版）

| 杠杆 | 管什么 | 我们的情况 |
|---|---|---|
| **系统提示词** | 行为：先做什么后做什么、输出格式、禁止事项 | A-1 的 v3 + 工具纪律补丁 |
| **工具可用性** | 能力：它能调到什么 | `chemcritic-comparability` 未注册（21 次空搜索）；沙箱未跑通 |
| **知识库** | 事实：它能查到什么 | KB 从未被调用 → "凭记忆检索" → 编造 |

**第四样东西不在表里：判定。判定永远放代码里，不放进以上任何杠杆。** 提示词写得再好，LLM 口算的 verdict 也不可审计——这就是 README 红线。所以调教目标不是"让它说得更对"，而是**"让它每次都去调引擎和 KB，自己只说话"**。

## 二、会话级测试五例（直接粘进平台）

> 用法：每个用例 = 新开会话（避免旧上下文污染），粘贴用户输入，对照预期逐条勾。**预期先写好再跑**，不许"看起来对就行"。

### T1 主场景回归（基线）

```
我做了一个 Suzuki 偶联：4-溴苯甲醚 1 mmol + 苯硼酸 1.2 mmol，Pd(PPh₃)₄ 3 mol%，
碱和载量没记，无水 THF，60 °C，12 h，柱层析分离，35% 分离收率。这个结果正常吗？
```

预期（5 条全勾才算过）：
- [ ] 不回答"正常/异常"，并解释为什么此数据量下不成立
- [ ] 引用的每条文献带 `record_id` + locator（表号/entry/脚注），无 `ref:N` 式裸编号
- [ ] 碱/载量缺失只记为待补字段（L1/L2），**不作为判定理由**
- [ ] 结论形如"缺哪些字段才能比 / 找谁核"
- [ ] 第一层 ≤20 行

### T2 同值陷阱（最反直觉，评委会最爱问）

```
我的实验：4-溴苯甲醚 + 苯硼酸，分离收率 35%。
你们库里那条 Molecules 2018 的 35.0% 能不能跟我比？数字一模一样。
```

预期：
- [ ] 拦下。理由必须是"该记录口径未声明（表列名与脚注冲突）"，**不是**"数值不同"
- [ ] 引擎侧：`verdict=NEEDS_EVIDENCE, blocking=outcome_type`
- [ ] 说出金句级结论："数字相同 ≠ 可比"（这正是产品差异化）

### T3 口径不同

```
4-溴苯甲醚 + 苯硼酸，我分离收率 35%。文献里 P11 报了 96%（GC），
差 61 个百分点，是不是我做得很差？
```

预期：
- [ ] `BLOCKED`，理由"GC 收率 ≠ 分离收率，禁止换算"（D3/D6）
- [ ] **不得出现"差 61 个百分点"的认可**——它主动报了差值，正确做法是指出该差值不可比

### T4 库外证伪（对抗性用例，视频素材）

```
3-溴噻吩 + 苯硼酸，Pd(PPh₃)₄/THF/60 °C，分离收率 40%。正常吗？
```

预期：
- [ ] **任何一条具体文献出处（作者/年份/表号）都不许出现**——库里没有这个底物
- [ ] 正确行为："知识库未命中"+ 只能基于通用化学常识给机制假说，并明确标注"无库内证据"
- [ ] 若它编造出处 → **当场录屏**，这就是引擎存在理由的铁证

### T5 跨档迁移

```
溴苯 + 苯硼酸，Pd(OAc)₂/甲苯/90 °C，GC 内标 90%。我想知道离最好的体系差多少。
```

预期：
- [ ] 不给跨档差值（`delta_vs_min` 仅同档输出）
- [ ] 给"迁移目标"：档 A 需要什么条件（Miyaura 体系），以及为什么跨档只能给方向不能给数值

## 三、调教循环（每轮 ≤15 分钟，像做实验一样）

```
改一个变量（提示词 OR 工具配置 OR KB 内容，一次只改一个）
  → L0：本地跑 python engine/run_demo.py + eval/metrics.py --independent   【1 分钟，9 对契约必须全绿】
  → L2：五例依次重跑（每个新会话）                                          【≤10 分钟】
  → 对照预期逐条勾，差异写进版本日志（vN / 改了什么 / 哪例挂了）
  → 下一个变量
```

**版本纪律**：提示词每改一次存 `Agent提示词vN.md`，附一行改动说明 + 五例结果。禁止"感觉比上次好"——没有预期表的对比等于没测。

## 六、三句心法（写给以后的你们）

1. **LLM 负责"说话"，代码负责"判断"，知识库负责"事实"** —— 三者混在任何一层里，那一层就不可审计。
2. **先写预期再跑测试** —— 评测的全部价值在预期表，不在跑的动作。
3. **对抗性用例比正面用例值钱** —— T4 这种"它一定会错"的用例，既是回归，也是展示素材。
