## 3. 新旧策略边界（给 C 的「不改」清单）

1. **v0.1 规则全部作废**：S2 不得由文献先例触发（无用户目标 → 不判「部分达到」）。已归档 `Desktop\ChemCritic-角色B\_deprecated\`，若 C 本地存有 v0.1 副本请删除。

4. **条件字段缺失不降状态**：只记 blocked/追问，不把「没填碱」渲染成「实验失败」。

## 6. 平台 agent 话术（今天截图发现，10/28 录视频前必须改）

SciencePal 上的 agent 对用户承诺了「我会给你**档内定位和差值**」：

- 「差值」违反数值比较关闭 + 新演示叙事（演示底物上 0 条可比参照）。评委若问「你的差值哪来的」无法回答。
- 建议改为：「我会给你档内定位——但只有在口径一致且校准齐备时；当前你的数据量下，正常/异常不成立，我们也不给差值。」
- 追问表单本身（碱/载量/规模/气氛）与规则设计的 followups 字段一致，**保留**；但用户事后补答的字段必须标 `user_recalled` 来源，**不得**因此提升 evidence_grade。
- 表单里「THF 无水体系里 Na2CO3 溶解性差」是 LLM 插入的化学论断（本身正确），录视频时要么给出处、要么口头标注为启发式提示，不要让它看起来像检索结果。
