# PDF 取证端到端验收（2026-10-30）

对照材料学智能体对比文档 §8 承认的"PDF 自主检索尚未端到端验收"，本次完成全链路验收。

## 数据来源（真实、可复核）

- 文献：Çakır, Kavukcu, Karabıyık, Rethinam, Türkmen, **RSC Adv. 2021, 11, 37684**，
  DOI `10.1039/d1ra07231e`，PMCID `PMC9043785`（RSC Advances，开放获取，CC-BY）。
- 选它的原因：Table 3c = 溴苯 + 苯硼酸 Suzuki（正好是库内 C4 用例底物），22 行收率表，脚注条件完整。
- 获取路径：出版商直链（MDPI/Beilstein/PMC/Europe PMC）在本机网络全被 CDN 拦截，
  改走 **NCBI E-utilities efetch**（`db=pmc`）拿出版级 XML——与角色 B 2026-10-27 批次同一路线。
- PDF 素材：`refs/pmc9043785_table3c.pdf` 由 `refs/make_typeset_pdf.py` 从 XML **逐字**排版
  （表格文字零改动，仅重排版 + 画框线；locator 引 DOI+表号，复核路径是 DOI 原文，不依赖本副本）。

## 修复的两个真实缺陷（本次验收的额外产出）

1. `--audit-table` 不认 extract 的多 PDF 输出（每 PDF 一个对象）→ 已在 CLI 归一层拍平。
2. `_row_to_payload` 值挑选取首个 ≤100 的数，Entry 号 "1" 被当收率 → 改为行尾数值列优先。

## 边界与诚实性说明

- 本机网络下出版商 PDF 直链全部被拦，"自主检索"在**平台沙箱**内验收（网络环境不同，
  bootstrap 已装 pdfplumber）；本次验收的是**取证管道本体**：抽取→审计→签核→入库→判定生效。
- 排版副本 PDF 仅作管道输入；对外的证据链始终是 DOI + 表号 + 逐字 label_raw。
- 签核停在 candidate 档，理由写进记录 `outcome.note`——口径推定不冒充 A_confirmed。
