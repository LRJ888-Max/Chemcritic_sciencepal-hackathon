## 三、这轮真正修好的四件事

1. **条件表标"未提供"**。R1 里碱 / 载量 / 气氛全部如实标「未提供，未提供」，没有出现 Na₂CO₃、3 mol%、N₂。上一轮最严重的"替用户编实验记录"已堵住主路径。

3. **`migration_targets` 接进输出**。R1 出现「同底物在其他体系下有更高记录……那属于换体系，不是调条件」。这是"窄"第一次变"宽"，引擎侧 `I2` 改动生效。
4. **引用精度到行**。「表 II，p-MeOPhBr 行，括号内数值」，不再是只有期刊卷页。

## 五、剩余问题：引擎层（2 项，C 改）

### E1 · `placement()` 不按底物过滤（结构缺陷，运行未暴露）

```python
# engine/placement.py 现状
same_class = [r for r in records if r.outcome_type == user.outcome_type]
```

3-溴噻吩输入下，`verdicts` 全 BLOCKED，但 `placement` 仍返回 `PLACED / [40] / delta = 0`。
**引擎内部自相矛盾**，模型每次自己选了 verdicts 那一侧（2/2 都选对）。

修法（3 行，不改函数签名，复用已有 `_same_pair`）：

```python
same_class = [r for r in records if r.outcome_type == user.outcome_type and _same_pair(user, r)]
if not same_class and any(r.outcome_type == user.outcome_type for r in records):
    return {"status": "NO_COMPARABLE",
            "reason": "同口径参照存在，但底物对或产物不同，不能并排比较",
            "action": "换回原底物，或为该底物补充同口径文献"}
```

### E2 · `soft_flags.detail` 泄漏 `None`

实测输出：`气氛不同：None vs n2`。模型把它写成「气氛不同（文献 N₂ vs 您未记录）」——**把缺失写成了差异**。

修法：`None` 渲染成「未记录」；`kind=missing` 的不进差异列表，或单列 `missing_fields`。

## 六、演示前必改的三处（画面可见）

这三处不改，录屏素材会被评委当场问倒：

1. **编造值**：`1.2 mmol` / `3 mol%` / `无水` 三个数，用户一个都没给。R1 和 R2 逐字复现，说明是模板泄漏，不是偶发。
2. **无效建议**：「补碱并重跑一次」。底物不同，重跑一万次也不能跟 4-溴苯甲醚比。这是科学性错误。
3. **超长**：五节全吐，一屏放不下；「展开」提前抖完，用户没有点击理由。

另有一处自相矛盾：R2 写「3-溴噻吩 **1 mmol**（规模待确认）」——写了值又标待确认。

## 七、可以直接进答辩的一句话

T4b 原文：

> **没有可比的参照值，就不存在"差多少"——差值只有在同底物同口径的参照存在时才有意义。**

这句比任何架构图都更能解释"为什么非要写引擎"。建议把 T4 这版输出留作素材，定位不是"它能干什么"，而是**"它拒绝的时候在说什么"**。
