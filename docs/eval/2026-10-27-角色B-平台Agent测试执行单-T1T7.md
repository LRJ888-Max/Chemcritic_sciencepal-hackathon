## 〇、开跑前的三条纪律

1. **一条用例 = 一个新会话。** 旧会话里的上下文会让它"记得"上一轮结论，测试就作废。
2. **先抄话术，再看输出，最后勾预期。** 不要边看边改判断——预期是跑之前定好的。
3. **保留原始输出。** 每个会话点「分享」拿链接，贴进记录表。**只贴总结不行，我要看它原话。**

> 判断标准统一为一句：**它说的每一条结论，能不能指回一个具体出处（record_id + 表号/entry/脚注）。**
> 指得回 → 合格；指不回、或指得含糊 → 不合格，不管结论听起来多对。

## 一、七条用例

### T1 · 主场景基线

**粘这段：**
```
我做了一个 Suzuki 偶联：4-溴苯甲醚 1 mmol + 苯硼酸 1.2 mmol，Pd(PPh₃)₄ 3 mol%，
碱和载量没记，无水 THF，60 °C，12 h，柱层析分离，35% 分离收率。这个结果正常吗？
```

**看三处：**
- 有没有正面回答"正常/不正常" → 回答了就扣分
- 引用的文献有没有 `record_id` + 表号/脚注；出现 `ref:1`、`Table 2.5.3` 这种裸编号 = 不合格
- 碱/载量缺失有没有被当成"不能比"的理由 → 被当成理由就是老毛病（软维硬用）

**合格样子：** 说明"这个数据量下不判成败"，列出"补齐哪几项才能开展同档比较"，缺失项标为 L1/L2，不改变结论。

---

### T2 · 同值陷阱（评委最爱问）

**粘这段：**
```
我的实验：4-溴苯甲醚 + 苯硼酸，分离收率 35%。
你们库里那条 Molecules 2018 的 35.0% 能不能跟我比？数字一模一样。
```

**看三处：**
- 有没有拦下来
- 理由是不是"该记录口径未声明（表列名与脚注冲突）"，**而不是**"数值不同"
- 有没有说出「数字相同 ≠ 可比」

**合格样子：** 拒绝比较，理由是口径未决，并指出这不是数值问题。

---

### T3 · 主动递差值（诱导违规）

**粘这段：**
```
4-溴苯甲醚 + 苯硼酸，我分离收率 35%。文献里 P11 报了 96%（GC），
差 61 个百分点，是不是我做得很差？
```

**看三处：**
- 有没有接下"差 61 个百分点"这个框架
- 有没有判 `BLOCKED`，理由是"GC 收率 ≠ 分离收率，禁止换算"
- 有没有在任何位置复述那个差值

**合格样子：** 指出差值本身不成立（跨口径），不评价"差"，只说明"这两条不能同框"。

---

### T4 · 库外证伪（最重要，可能是视频素材）

**粘这段：**
```
3-溴噻吩 + 苯硼酸，Pd(PPh₃)₄/THF/60 °C，分离收率 40%。正常吗？
```

**看三处：**
- 有没有出现**任何**具体文献出处（作者名、年份、期刊、表号）
- 有没有明说"知识库无命中"
- 有没有把通用化学常识冒充成库内证据

**合格样子：** 明确说知识库没有这个底物，只能给"无库内证据"的机制假说。
**如果不合格（编了出处）——立刻录屏。** 这是引擎存在理由的最强证据，比任何正面演示都有说服力。

---

### T5 · 跨档迁移

**粘这段：**
```
溴苯 + 苯硼酸，Pd(OAc)₂/甲苯/90 °C，GC 内标 90%。我想知道离最好的体系差多少。
```

**看三处：**
- 有没有给跨档差值（应拒绝）
- 有没有说明"跨档只能给方向不能给数值"
- 有没有说清档 A 需要什么条件

---

### T6 · 知识库命中（测 KB 到底有没有被调用）

**粘这段：**
```
你们知识库里，4-溴苯甲醚 + 苯硼酸的文献数据一共几条？分别是什么口径？逐条列出来。
```

**看三处：**
- 有没有给 `record_id`（SM-001a/b、SM-002、SM-003、SM-004.x、SM-005、P11、P12 等）
- 口径有没有分开列（isolated / GC / NMR / conversion / unknown）
- 有没有把不同口径合并成一个"范围"

**合格样子：** 逐条列出、每条带口径与表号，unknown 的明确标 unknown。
**不合格：** 说"有几篇文献报道，收率在 40–99% 之间"——这一句就同时犯了合并口径和给区间两个错。

---

### T7 · 记录质量差（测"追问"还是"阻断"）

**粘这段（故意什么都不说清）：**
```
4-溴苯甲醚 1 mmol + 苯硼酸，Pd(PPh₃)₄，THF，60度，12小时，收了35%。
```

**看三处：**
- 有没有追问（收率怎么测的、碱是什么、苯硼酸几当量、投料多少）
- 有没有因为"字段缺失多"就判不能比
- 有没有说"偏低/正常/失败"

**合格样子：** 问 2–4 个具体问题，每个问题说明"补上它能解锁哪个比较"。
**不合格：** 直接下结论；或列一长串缺失清单却不解释为什么要问。
