# 新增文献操作手册（给队友 / 也可以直接扔给你的 AI）

> **版本：** 对齐 **引擎 1.7.3**（2026-10-31 从 GitHub `origin/main` 同步后重写）。
> 若 `engine/version.py` 不是 1.7.x，先 `git pull`，否则本手册的命令对不上。
>
> **一句话原理：** **PDF 不会被 Agent 读取。** 把 PDF 放进 `refs/pdf/` 只是留证据；Agent 能"用上"一篇文献的唯一条件，是**有一条记录被写进 `data/records.json` 并烘焙进引擎**。
> 所以你要交的是**两样东西**：① PDF；② 一条记录 JSON。然后跑**一条命令**。

---

## 0. 先查重（30 秒，别跳）

```powershell
Select-String -Path data\records.json -Pattern "你的DOI" -SimpleMatch
python skills\chemcritic-comparability\scripts\chemcritic_engine.py --find-substrate 4-bromoanisole
```

命中就**不要加**。`record_id` 是主键，重复会被入库脚本拒绝；但**同一篇文献的不同底物/不同条目可以是两条记录**（如 P40 与 P41 同篇、底物不同）。

## 1. 放 PDF

- 位置：`refs/pdf/`
- 命名：`NEW-<期刊缩写>-<年>-<卷>-<文章号>.pdf`，如 `NEW-scirep-2024-14-7688.pdf`
- 要求：**必须有文本层**（能选中文字）。扫描件抽不出字，只能人读，`locator` 也写不准。

**下载实测（2026-10-31）**：

| 出版社 | 能否脚本下载 |
|---|---|
| MDPI（`10.3390`） | ✅ `https://mdpi-res.com/d_attachment/<刊>/<刊>-<卷>-<5位文章号>/article_deploy/<刊>-<卷>-<5位文章号>.pdf` |
| Nature / Sci Rep（`10.1038`）、Frontiers（`10.3389`） | ✅ 文章页 `.pdf` |
| Beilstein（`10.3762`） | ✅ `/bjoc/content/pdf/...` |
| **ACS（`10.1021`）、RSC（`10.1039`）、Hindawi、Royal Society** | ❌ 一律 403，**只能人工用浏览器下载** |

## 2. 写记录 JSON（唯一需要动脑的一步）

新建 `data/incoming/P<下一个号>.json`。先跑 `--list-records` 看现有最大号，**ID 不能重复**。

### 2.1 完整模板（照抄改值）

```json
{

    "calibration": "calibrated"
  }

```

### 2.2 四个最容易填错的字段

**① `outcome_type` —— 只能填这四个之一，按原文写，不许猜**

| 原文怎么写 | 填什么 | `calibration` |
|---|---|---|
| isolated / 分离 / 柱层析后称重 / 蒸馏 / 重结晶 | `isolated` | `calibrated` |
| GC / GLC / 气相，**且写了内标** | `gc` | `calibrated` |
| GC，**没写内标** | `gc` | `uncalibrated` |
| ¹H NMR 定量，**且写了内标** | `nmr` | `calibrated` |
| NMR，没写内标 | `nmr` | `uncalibrated` |
| conversion / 转化率 | `conversion` | 同上规则 |
| **表头只写 Yield (%)、脚注没说什么** | **`unknown`** | `uncalibrated` |

> 拿不准就写 `unknown`。写 `unknown` 只是"不参与比较"；写成错的 `isolated` 会让整条结论失真。

**② `label_raw` —— 必须含口径关键词，否则入库脚本直接拒**

- `isolated` 需含 `isolated` / `分离` / `称重` / `weighed`
- `gc` 需含 `gc` / `glc` / `气相`
- `nmr` 需含 `nmr` / `核磁` / `1h`
- `conversion` 需含 `conversion` / `转化`

**③ `tier` 不是证据等级**

`tier` 由 `engine/tier.py` 从 `catalytic_profile` 计算，你只要把 profile 填对（受控词表）：

| `catalyst_form` | `ligand_family` | `support` | `medium` | `activation_mode` |
|---|---|---|---|---|
| `molecular_complex` / `in_situ_salt` / `nanoparticle` / `supported` | `phosphine` / `non_phosphine` / `none` | `none` / `solid_support` | `aqueous` / `organic` / `solventless` | `thermal` / `mechanochemical` / `microwave` / `photochemical` |

> 词表外的值（如 `supercritical`）会让档位算不出来，`--selftest` 会报 MISMATCH。sc-CO₂ 要映射成 `organic` 并在 `_extraction` 里注明。

**④ `evidence_grade` —— 只在真的读过原文后填 `A_confirmed`**

| 值 | 含义 |
|---|---|
| `A_confirmed` | 已打开原文，数字能对上表号/页码 |
| `candidate` | 读过，但口径或校准有歧义（如只写 "GC yield" 没写内标） |
| `imported_unchecked` | **没读原文，禁止用于新记录** |

## 3. 一条命令：校验 + 入库 + 重建 + 自检

```powershell
# 先 dry-run 看会不会被拒
python scripts\append_verified_record.py data\incoming\P42.json

# 确认后写入（自动重建引擎并跑 selftest）
python scripts\append_verified_record.py data\incoming\P42.json --write
```

它做四件事，**任何一步失败就停**：

| 步骤 | 作用 |
|---|---|
| ① 校验 | 复用 `merge_corpus_records.check()` 同一套入库门槛；被拒则**整批不写** |
| ② 写入 | 追加到 `data/records.json`（`record_id` 去重） |
| ③ 重建 | `engine/build_bundle.py` 把记录**烘焙进** `skills/chemcritic-comparability/scripts/chemcritic_engine.py`（**Agent 读的就是这份**） |
| ④ 自检 | `build_bundle.py --check`（产物与源一致）+ 引擎 `--selftest`（应看到 `29 passed, 0 failed`） |

> 只改了数据想手动重建，等价命令是仓库根目录的 `rebuild.bat`（build → check → selftest 三步）。

## 5. 验收：怎么确认"真的进 Agent 了"

```powershell
# 最硬的一条：引擎按底物能查到你的新记录
python skills\chemcritic-comparability\scripts\chemcritic_engine.py --find-substrate 4-bromoanisole
```

检查清单：

```
[ ] append 脚本最后打印的「总条数」比之前 +1
[ ] build_bundle 打印的引擎行数变大
[ ] --check 输出「产物与源文件一致」
[ ] --selftest 输出 `29 passed, 0 failed`
[ ] --find-substrate <你的底物> 里能搜到你的 record_id
[ ] refs/pdf/MANIFEST.csv 有那一行
```

只满足第 1 条、不满足第 5 条 → 说明没重建，Agent 还是旧数据。

## 6. 报错对照表

| 报错 | 原因 | 怎么修 |
|---|---|---|
| `✗ PXX: label_raw 不支撑 outcome_type=isolated` | label 里没有口径关键词 | 补"分离/称重"等原文措辞 |
| `✗ PXX: record_id 已存在` | 重复入库 | 换 ID，或确认是否同篇不同条目 |
| `有记录被拒，整批不写入` | 任意一条失败就全回滚 | 按报错逐条改 |
| `--selftest` 里 `MISMATCH tier=-` | `catalytic_profile` 用了词表外的值 | 改成词表内值（见 2.2 ③） |
| `--check` 报"产物与源不一致" | 忘了重建就提交 | 先 `build_bundle.py` 再 `--check` |
| PDF 下载 403 | ACS/RSC/Hindawi/Royal Society 拦脚本 | 浏览器手动下，放进 `refs/pdf/` |

## 7. 禁止清单（踩了会污染整个结论）

1. ❌ **猜数字。** 原文没写就写 `unknown`，不许补"看起来合理"的值。
2. ❌ **手改 `data/records.json`。** 走 `scripts/append_verified_record.py`（复用同一套门槛）。
3. ❌ **只把 PDF 扔进文件夹就以为完事。** Agent 看不到。
4. ❌ **把 GC/转化率写成 `isolated`。** 本项目最致命的错误类型。
5. ❌ **拿不同底物的收率互相做差。** 4-溴甲苯的 99% 不能和 4-溴苯甲醚的 35% 比。
6. ❌ **同一篇文献的两个条目当两条独立来源。** 要标 `non_independent`。
