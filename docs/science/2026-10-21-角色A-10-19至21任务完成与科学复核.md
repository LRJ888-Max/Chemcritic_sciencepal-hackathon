## 1. 本轮结论

1. 首期演示底物仍为 **4-溴苯甲醚 + 苯硼酸 → 4-甲氧基联苯**。本轮将 Beilstein 2018（DOI: 10.3762/bjoc.14.160）核为新增直接底物记录 SM-006：Table 2 entry 1 报 92% GC yield。该文未证明与 SM-004 使用相同内标/校准口径，**不得用于开启数值比较**。
2. 遵循 B v0.2，MVP **不做文献收率区间比较**。现有直接底物记录覆盖 GC/GLC、¹H NMR 和分离收率等不同结果类型；同底物不等于同测定口径，也不等于同条件。
3. 用户只说“NMR 匹配”，但没有提供可审核的谱图或结构表征材料时，记为 `user_report_only`。这只是用户陈述，**不能自动置 `product_confirmed=true`，不能据此判 S1/S2**；按 B v0.2 的 S3 证据不足路径处理，并追问可支持结构确认的证据。若用户提供了谱图，仍需遵循项目定义的审核流程，不能只凭“有附件”就自动判真。
4. SM-004 entry 1 的 **35.0** 和 entry 7 的 **91.9** 均保留原始数值及原文位置，但 `outcome_type=unknown`。原表列名写 “Yield (%)”，脚注又说 “total conversion determined from the internal standard yield ... based on GC”。在缺少作者进一步澄清的情况下，不能把表列名和脚注揉成一个确定的“GC 收率”或“总转化率”。两条数据属于同一篇论文，且催化剂、温度、时间同时不同，不能算两条独立来源或用于单因素因果归因。
5. SM-002 / SM-003 的 RSC 官方文章页列有 SI 入口，但项目现有 PDF 包和 `refs/` 中没有对应 SI 文件；旧直链无法保存为有效 PDF。状态应写为“官方入口已确认、SI 文件未落盘、entry 级信息待拿到官方 SI 后复核”，不能称完整 SI 核验已结束。

```json
{
  "characterization_status": "user_report_only",
  "product_confirmed": false,
  "status": "S3",
  "reason_code": "characterization_evidence_unverified",
  "note": "用户称 NMR 匹配，但未提供可审核的表征证据；不将自述自动升级为产品确认。"

```

`product_confirmed=false` 在这里表达“系统目前没有足够证据确认”，不代表断言用户没有得到目标产物。不要将用户自述覆盖成 `characterization` 原始证据；应分开保存 `user_report` 与 `verified_characterization_evidence`。

### 建议追问

- 请提供用于结构确认的 NMR 谱图或可审核的峰表/解析结果，并注明样品与目标产物的对应关系。
- 这是结构鉴定证据还是定量证据？如果用户把 NMR 用来报收率，还需说明是否使用内标、校准方法和计算方式。

仅提供结构匹配信息，不等同于 qNMR，也不自动支持纯度或定量收率结论。

## 4. 新增候选来源：SM-006

### 文献与定位

Fiebor et al., “Water-soluble SNS cationic palladium(II) complexes and their Suzuki–Miyaura cross-coupling reactions in aqueous medium,” *Beilstein Journal of Organic Chemistry* 2018, 14, 1859–1870. DOI: [10.3762/bjoc.14.160](https://doi.org/10.3762/bjoc.14.160)。项目本地 PDF：`refs/pdf/P08_beilstein-14-160.pdf`；PDF 在本地包内文件 `outputs/2026-10-21-Suzuki文献包/PDF/01_Beilstein2018_SNS-Pd_直接底物.pdf`。PMC 全文入口：[PMC6071702](https://pmc.ncbi.nlm.nih.gov/articles/PMC6071702/)。

**处理状态：原文表项与主要反应条件已核实，可作为结构化直接底物来源 SM-006；暂不作为数值比较基准。** 官方全文 Table 2 entry 1 和脚注明确列出底物对、条件及 `GC yield`；未确认与 SM-004 的 hexadecane 内标/校准口径相同，因此仍不满足 B v0.2 的同 assay 比较门槛。

| 审核项 | 本轮结果 |
|---|---|
| 底物相关性 | 直接研究 4-bromoanisole + phenylboronic acid；可作精确底物候选 |
| 表/entry 及条件绑定 | 官方全文 Table 2 entry 1；主文说明使用等摩尔底物 |
| 条件 | 4-bromoanisole + phenylboronic acid，等摩尔；K₃PO₄ 2 eq；水；SNS-Pd pincer complex 17a，1 mol%；140 °C，4 h |
| 结果口径 | 92% GC yield（Table 2 footnote a）；内标、校准、定量计算细节未见于该表脚注 |
| 与 SM-004 可比性 | 不足；不能证明 assay/calibration 同口径 |
| MVP 用途 | 结构化直接底物先例、检索相关性与字段抽取；不参与数值范围、平均值或状态判定 |

文章 Table 3 entry 1 另报 93% GC / 88% isolated yield，但该表脚注明确为另一组优化条件（17d、0.5 mol%、ArX 1.63 mmol、ArB(OH)₂ 2.61 mmol、H₂O 2 mL、KOH 3.26 mmol、120 °C、2 h、TBAB 0.5 eq）。不要把 Table 2 的 92% 与 Table 3 的 93%/88% 合并成同一条件结果。不得因为此文提及 GC 就推定与 SM-004 的 hexadecane 内标 GC 口径一致。
