## 1. 选条逻辑（为什么是这 15 条）

34 条候选池里，只有 **7 条**是演示底物对（4-溴苯甲醚 + 苯硼酸）。其中 4 条已经是 SM-001 / SM-004 / SM-005 / SM-006 本身。**真正新增的同底物记录只有 3 条**：P11、P12、P13。

所以"抽 15 条"不能靠同底物堆量，我按**能产出什么判定**来选：

| 组 | 目的 | 条目 | n |
|---|---|---|---|
| **G1 同底物新增** | 补充档 C 的同底物参照；覆盖 isolated / gc / conversion 三种口径 | P11、P12、P13 | 3 |
| **G2 篇内条件扫描** | 同一篇里只换一个条件，天然生成"应判 COMPARABLE"的对，是唯一可靠的 PASS 类样本来源 | P19a/P19b（换碱）、P24a/P24b（换溶剂）、P23（同溶剂换载量） | 5 |
| **G3 同底物不同类型的反例** | 证明"条件对了也不一定高收率"，防止把单一条件写成因果 | P27（球磨 77% conversion）、P20（缺温度仍 85%）、P21（10 min 91%） | 3 |
| **G4 维度 1 的确定失败样本** | 测 BLOCKED:substrate 与 D1（离去基不同即不同底物） | P03（邻位异构）、P06（吸电子醛）、P07（芳基碘）、P33（吸电子酮） | 4 |

**为什么不是别的 19 条：** P01/P04 是另一个底物的同批条件（与 P03 信息重复）；P05 是综述（无单一数值，按 A 报告不得引用数字）；P14/P15 付费墙未读、无数字；P16/P17/P18/P22/P25/P26/P28–P32 与 G2 的 P19/P24 在"篇内扫描"这一功能上重复，边际信息低。**这是取舍，不是穷尽**——10/26 若要把 30 条补齐，缺口清单在 §7。

## 4. 四个必须让 A 先知道的发现

### F1 · 候选池修不了"档 A 单点参照"，而且方向更糟

10/25 我提过：档 A 在演示底物上的分离收率只有 1 条（SM-001b 的 40%）。当时的建议是"在 34 条池里找 1–2 条档 A + isolated 的同底物记录"。

**抽完 15 条后可以确定：池里没有。** 34 条候选里同底物的 7 条，分档结果是 **3 条档 C（P11/P12/P13）+ 4 条已入库**，**新增的档 A / 档 B 同底物记录数 = 0**。

档 A 的两条新记录（P03、P06）都不在演示底物上：P03 是邻位异构，P06 是吸电子醛。它们能做维度 1 的 FAIL 样本，**不能**给档 A 补参照。

→ **"档 A 只有 1 条同口径参照"这句限制，10/31 之前不会变。** 建议把它从"待解决的局限"改成"演示里主动说出的事实"（现有 `docs/rules/分档定义-待签字.md §8` 已经这么写了，保持一致即可）。

### F2 · SM-006 与 P08 是同一篇文献，但两处对不上

| | LITERATURE.md / records.json 的 SM-006 | 核验报告表 1 的 P08 |
|---|---|---|
| 文献 | Fiebor et al., *Beilstein J. Org. Chem.* 2018, 14, 1859 | 同一篇（同卷同页） |
| 收率 | **92%**（GC） | **95%**（GC） |
| 碱 | **K₃PO₄** | **K₂CO₃** |

同一篇文献、同一个底物、同一个口径，**收率和碱各差一处**。这不是"两种写法"，至少有一处是转录错误。**请 A 拍板哪个对**——因为：

- 若 92% / K₃PO₄ 对，`docs/rules/分档定义 §3` 里 SM-006 归 C 的理由（"SNS-Pincer / K₃PO₄ / H₂O / 140 °C"）成立；
- 若 95% / K₂CO₃ 对，碱换了但档不变，**但 92 这个数字会进 ≤5 页说明和视频字幕**，错了就是评审能一眼看出的错。

我没有把 P08 放进 pool15，就是为了不把冲突值带进评测集。**这一条进不了 gold set，直到 A 定值。**

### F3 · 维度 4 第三层没写 `conversion` 要不要校准

`8维门槛规则表 §2.4` 第三层只给了 `isolated` / `gc` / `nmr` 三行的要求，**`conversion` 没有行**。而候选池里有 2 条 conversion（P13 的 100%、P27 的 77%），且 D6 刚定"conversion 不得与 gc 同框"。

按现在的表，`conversion` 走完第一层（label_raw 含 "conversion"）就没有第三层要求 → **可能被判 PASS**。但转化率同样需要定量依据（内标或外标）。这是规则表的漏项，不是实现 bug。

→ **建议 A 补一行：** `conversion` 要求"定量方式 + 以何物计（芳基卤/硼酸）"，缺任一 → UNKNOWN。否则 gold set 里 conversion 类样本会得到"假绿灯"。

### F4 · 13/15 的 `label_raw` 是转述，会让维度 4 第一层"假绿"

我按 A 报告的括注填 `label_raw`（例：P19a 填 `"95% (GC)"`）。A 报告写的是 `95%（GC）`，但**这个括注是 A 的归纳，不一定是原文单元格的措辞**。

后果很具体：规则表 T14 就是为这件事写的——"标记写 `isolated`，但原文只有 `Yield (%)`"应判 `NEEDS_EVIDENCE 维度 4 第一层`。而我这 13 条的 `label_raw` 天然含 `gc`/`isolated`/`nmr` 字样，**第一层检查会 100% 通过**，T14 想防的漏洞在真实数据上根本没被测到。

→ 每条记录里已加 `_extraction.label_raw_provenance`：
- `transcribed` 13 条（A 报告括注，**待替换为原文逐字**）
- `inferred_same_table` 2 条（P19b、P24b：绝对值来自同表其他行已标口径的行，属推定）

**请 A 在 10/26 抽检时，把 `transcribed` 的 13 条替换成原文单元格逐字。** 这一项的成本很低（每条看一眼表格），但它决定 T14 是"真测过"还是"自己骗自己"。

## 5. 定量结论：这 15 条能做什么、不能做什么

用 4 个用户档（演示的 4-溴苯甲醚/35% isolated，加溴苯的 isolated / gc / nmr 各一档）× 15 条 = **60 对**，实跑 `gates.judge()`：

| 场景 | COMPARABLE | NEEDS_EVIDENCE | BLOCKED |
|---|---|---|---|
| **今天（全部 `imported_unchecked`）** | **0** | 全部非 BLOCKED 都在这里 | 52 |
| A 核验完证据等级（不改 assay） | **3** | 5 | 52 |
| A 再把内标/基准补齐 | **8** | 0 | 52 |

**三件事必须同时说清楚：**

1. **今天 FPR / FNR 无定义**，不是"很好"。COMPARABLE 分母为 0，`eval/metrics.py` 会输出 `fpr: 0.0` —— 这是**除零兜底，不是成绩**。把 0 写进评测报告是错的，评委一问就塌。

2. **A 的核验是唯一能把分母从 0 抬起来的动作。** 维度 4 第二层要求 `evidence_grade = A_confirmed`，我作为抽取方只能给 `imported_unchecked`。这不是流程繁琐，是产品主张的必然：我们卖的就是"核验过的数"。

3. **补齐后上限也只有 8 对，其中 5 对来自溴苯。** 演示底物（4-溴苯甲醚）上，**全池能同框的比较只有 1 条：P12（>99% isolated，档 C）**。

**"87% 的对都判 BLOCKED"要不要写进报告？要，而且是卖点不是缺点。** 这 52 条 BLOCKED 里有 39 条是"底物不同"、13 条是"口径不同"——它们每一个都能给出阻断维度和解锁条件。这正是"通用 LLM 会说'很好，高达 99%'，我们说'不能比，因为……'"的证据。**BDA（维度归因准确率）在这个规模上比 FPR 有分辨力**，这条我在 10/25 的标注手册里已经写过，这里有了 52 个真实样本支撑。

## 7. 对 gold set 的影响与建议

**问题：** 10/27 要求标完 12–15 对。用演示底物做，COMPARABLE 上限 = 1（P12），其余全是 BLOCKED / NEEDS_EVIDENCE。这样的 gold set 只能测"会不会乱比"，测不了"会不会漏比"（FNR 分母 1，一个错就 100%）。

**三个选项，我建议 ①+②：**

| | 做法 | 代价 |
|---|---|---|
| **① 加第二个底物档** | gold set 引入溴苯（+ 苯硼酸）作为第二用户档，含 isolated / gc / nmr 三档。化学上干净，只是不是演示底物 | 报告里必须写明"评测覆盖 2 个底物对，演示仅用 4-溴苯甲醚"，不能让评委以为演示用的是溴苯 |
| **② 用篇内条件扫描做 PASS 类** | P19a/P19b、P24a/P24b、P23 vs P24b 这三对，天然是"条件变、口径不变"的 COMPARABLE | 需要 A 确认同表口径一致（§6 P1 项） |
| ③ 只标 BLOCKED | 老实说"我们的评测只证明不乱比" | FNR 无法测；且 12–15 对全是同一类，样本同质，说服力弱 |

**建议 final gold set 的构成（14 对）：** 4-溴苯甲醚 5 对（含 P12 的 COMPARABLE、P03/P06/P07/P33 的维度 1 FAIL） + 溴苯 7 对（3 条篇内扫描 COMPARABLE + P27 conversion + 其余） + 2 对 assay 层 UNKNOWN（P11 与 P19a 的 gc 缺内标）。**每类都有 ≥2 个样本**，FPR 与 FNR 才有分母。

**一个建议但不强求的第 16 条：** P24c（溴苯，THF 中 0% NMR）。`0` 和 `null` 在实现里极易混淆（`if not value` 会把 0 当缺失），这是最便宜的一个边界测试。要的话我 30 分钟加上。
