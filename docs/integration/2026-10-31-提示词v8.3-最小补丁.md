# 提示词 v8.2 → v8.3 最小补丁（不想整份重贴时用这个）

**前提**：平台上的提示词已经是 **v8.2**（即第二节已经有「产物只推定 → 并排看区间、不给差值」那一档）。
如果平台上还是 v8.1，本文件不适用——v8.1 缺的不是这几行，而是整个第三档，见文末。

为什么要打补丁：v8.3 相对 v8.2 一共改了 9 处，但其中 **5 处在附录**（第 514 行以后，标注「不进提示词」，
只供人眼确认格式），对 agent 行为没有影响。真正会改变回答的只有下面 3 条。

---

## 补丁 1 · 必改｜第二节把 `NEEDS_EVIDENCE` 一律说成"收率定义不清"

**为什么必改**：产物只推定那一档的 verdict 恰好是 `NEEDS_EVIDENCE`（`blocking_dimension = product`）。
查这张表就会把"产物没逐字记录"译成"收率定义不清"——**归因错，而且演示必现**（走第二档就会命中）。
数值不会错，错的是"卡在哪"。

**查找**（在「# 用语规范（对外一律遵守）」的表格里）

```
| NEEDS_EVIDENCE | 收率定义不清，需先确认原文 |
```

**替换为**

```
| NEEDS_EVIDENCE | **按 `blocking_dimension` 分两种，不许混用**：= product → 「产物结构两侧都没逐字记录，需先确认产物名」；其他（口径/当量/催化体系/后处理）→ 「收率定义不清，需先确认原文」 |
```

---

## 补丁 2 · 必加｜没有「档位定不了」这一档

**为什么必加**：用户只说"我做到 70%"、不给催化体系时，引擎返回 `TIER_UNKNOWN` 且
`reference_count = 0`。v8.2 没有对应分支，agent 只能落到"不可比"去，很容易说成
**"库里没有可比数据"——这是事实错误**（库里有 12 条，是条件不够，划不出等价类）。

**查找**（第二节最后一个分支的开头）

```
· 不可比 / 口径未决（NEEDS_EVIDENCE、UNDEFINED、无可比参照）：
```

**替换为**（把新档插在它前面）

```
· 档位定不了（placement.status = TIER_UNKNOWN，此时 reference_count = 0）：
  **绝对不许说"库里没有可比数据"**——库里有这个底物对的记录，是用户给的条件不足以定位档位
  （comparables 为空是这个原因，不是没数据）。照 placement.reason 说清，并逐项列出要补的五项
  （说人话，不用受控词表术语）：
  ① 催化剂形态（可溶的分子配合物 / 原位生成 / 纳米颗粒 / 负载型 / 金属块）
  ② 配体（膦配体 / 非膦配体 / 无配体）
  ③ 载体（无 / 固体载体）
  ④ 介质（水相 / 有机相 / 无溶剂）
  ⑤ 活化方式（加热 / 研磨 / 微波 / 光照）
  **五项缺一不可**（缺任何一项引擎都判不出档）；补齐后重跑才可能给出区间。
  本节不出现任何参照数值——因为你还没有可比面。

· 不可比 / 口径未决（NEEDS_EVIDENCE、UNDEFINED、无可比参照）：
```

## 补丁 3 · 建议改｜推定依据点名了"Heck 型"

**为什么要改**：证书里**根本没有 `reaction_class` 字段**（只有 `--find-substrate` 的
`by_reaction_class` 才有）。把"Heck 型"写死在提示词里，遇到 Suzuki / Sonogashira 就会说错化学。
演示用 Heck 案例时恰好是对的——所以这条不必然暴露，但一旦被换个反应问就露。

**查找**（第二节「产物只推定」那一档内）

```
  INFERRED 时补一句推定依据：芳卤 + 烯烃 → Heck 型，产物结构按反应类型推定，不是原文逐字写出。
```

**替换为**

```
  紧接一句推定依据：「产物结构按两侧底物推出的同一类转化推定，不是原文逐字写出」。
  **不许自己给反应类型起名**（"Heck 型""Suzuki 型"等）：证书里没有这个字段；
  只有用户原话说了、或 `--find-substrate` 的 `by_reaction_class` 里有的，才可以写名字。
```

## 补丁 4 · 可选｜用户回"展开"时差值列会空

**为什么可选**：只有用户回"展开"才触发，主回答不受影响。但展开后表里"差值"列空着会露馅。

**查找**（第二层第 ③ 条）

```
③ 只列"可以并排比较"的条目（表：文献 / 收率 / 测定方式 / 差值 / 说明），最多 4 行；
```

**替换为**

```
③ 只列"可以并排比较"的条目（表：文献 / 收率 / 测定方式 / 差值 / 说明），最多 4 行；
   ★ 无差值时（产物只推定 / 跨档）"差值"列写"—"，表下加一句"产物未逐字记录，只并排看区间、不计差值"；
     且表里必须出现区间两端与总条数 N。
```

对应地，第 ④ 条里"算术差"要允许删掉：

```
④ 与参照值的对照（≤3 行）：你的值、参照值、算术差、参照条数与单点限制
   ★ 无差值时删掉"算术差"，改成"你在区间内 / 区间外 + 区间由哪几条构成"，不许为填空编一个差值。
```

## 如果你平台上还是 v8.1

那**不是打补丁能解决的**：v8.1 的第二节只有"能比 / 不能比"两档，没有中间档，
产物只推定时一律走"不可比"、藏掉区间——96 条语料晋升记录在回答里全部不可见。
这种情况要整份重贴 v8.3。

判断方法：在平台上问「iodobenzene 和 methyl acrylate，我做到 70% 分离收率，跟文献比怎么样」，
给全五项催化信息（催化剂形态 / 配体 / 载体 / 介质 / 活化方式）：

| 回答 | 说明 |
|---|---|
| 「能和 12 个数据点并排看区间 60–96%，但不给差值」 | 已经是 v8.2/v8.3，打补丁即可 |
| 「不能比较，卡在产物结构」 | 还是 v8.1，需整份重贴 |
| 「不能比较，卡在**收率定义**」 | 是 v8.2 但补丁 1 没打（归因错） |
| 「库里没有可比数据」 | 是 v8.2 但补丁 2 没打（说错了） |
