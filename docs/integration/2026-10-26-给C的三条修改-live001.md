# 给 C 的三条修改（基于 live-001 实测）

**日期：** 2026-10-26 23:30
**来源：** `docs/science/2026-10-26-角色B-平台首轮实测复核-live001.md`
**范围：** 只改适配层与输出层，**不动规则引擎**（`engine/gates.py` 已判定正确，问题出在"怎么表述"）

---

## 修点 1 · 判定归因改为「逐维输出 + 硬维优先」

**问题：** 首轮实测里，Agent 用"碱、载量、规模、气氛、当量比 大量 UNKNOWN → NEEDS_EVIDENCE"来解释结论。**这些全是 D5–D8 软维**，阻断理由只能来自 D1–D4。

**改法：** 把 `gate_diagnostics` 的输出结构改成逐维两段式，且 `reason` 字段**只允许取硬维**：

```python
{
  "hard": {
    "D1_substrate":    "PASS",
    "D2_product":      "PASS",
    "D3_outcome_type": "PASS",
    "D4_assay":        "PASS"   # 或 "FAIL:口径不同" / "UNKNOWN:文献侧未核验"
  },
  "soft": {
    "D5_scale":      "L2 规模未记录",
    "D6_catalyst":   "L1 载量不同",
    "D7_conditions": "L2 溶剂族不同；L2 温差 20 °C",
    "D8_workup":     "L1 双方均未记录纯化方式"
  },
  "verdict": "COMPARABLE",          # 只由 hard 决定
  "reason": null,                    # 非 BLOCKED/NEEDS_EVIDENCE 时为 null
  "blocking_dimension": null         # 只能是 D1–D4
}
```

**验收：** 对"用户 35% isolated vs SM-001b"这一对，输出必须是
`verdict=COMPARABLE`、`blocking_dimension=null`、四条软维均为 L1/L2，
**不得**出现 `reason="大量字段未知"` 这类以软维解释结论的写法。

---

## 修点 2 · 禁止输出数值差值（含"虽然不成立但…"句式）

**问题：** live-001 的 ④ 写了"与 95% 差 60 个百分点"，虽然标了"不成立"，**数字已经出来了**。

**改法：** 在输出层加一个过滤器：当 `placement.status != "PLACED"` 时，正文里**任何**形如
`差 N 个百分点` / `低于 X%` / `高出 X 个百分点` / `X% vs Y%` 的表述都要被拦下。

```python
DIFF_PATTERNS = [
    r"差\s*\d+(\.\d+)?\s*个百分点", r"低\s*于\s*\d+(\.\d+)?\s*%",
    r"高\s*出?\s*\d+(\.\d+)?\s*个百分点", r"\d+(\.\d+)?\s*%\s*(vs|对比|相比)\s*\d+(\.\d+)?\s*%",
]
# 命中即拦截，并把该句替换为：
# "本次不给出数值差值（同档同口径且 calibrated 的参照不足）"
```

**验收：** 同上一对，④ 只出现"档 A / 同口径参照 40% / 单点参照"这类定性表述，**不出现任何差值数字**。

## 修点 3 · 引用必须带 locator，否则进"待核清单"

**问题：** live-001 的引用全是 `ref:1 / Table 2.5.3 e3 / "大连理工"`，无作者、无年份、无 DOI。

**改法：** 检索结果落成固定结构，缺 DOI/URL 的**不得进入正文**：

```python
{
  "authors": "...", "year": 1981, "journal": "...",
  "doi_or_url": "https://doi.org/10.1080/00397918108063618",
  "table": "Table II", "entry": "p-MeOPhBr 行", "footnote": "括号内数值",
  "locator_complete": True
}
```

`locator_complete = False` 的条目 → 只能进「待核清单」，不得出现在「可比性判定」表里。

**验收：** 每一条进入 ③ 表的记录都必须能同时给出作者 + 年份 + DOI 或 URL + 表号/entry。给不出 → 该条不出现。
