## 2. 判定调用契约（平台 Agent ↔ 沙箱）

### 2.1 输入：`Record`（`engine/schemas.py`）

平台 Agent 把用户实验与文献记录都构造成 `Record`（用 `Record.from_dict`），关键字段：

```json
{
  "record_id": "USER-001",
  "outcome": {"value": 35, "outcome_type": "isolated", "label_raw": "分离收率（柱层析）"},
  "conditions": {"catalyst": "Pd(PPh3)4", "catalyst_mol_pct": 3.0, "base": "Na2CO3",
                 "base_eq": 2.0, "solvent": "THF", "temp_c": 60, "time_h": 12,
                 "atmosphere": "N2", "scale_mmol": 1.0,
                 "equivalents": {"aryl_halide": 1.0, "boronic_acid": 1.2}},
  "assay": {"method": "isolated (weighed)"},
  "substrate": {"aryl_halide": "4-bromoanisole", "boronic_acid": "phenylboronic acid",
                "product": "4-methoxybiphenyl"}
}
```

**约束：** 原文未报告字段一律 `null`（`from_dict` 已处理）；禁止用默认值补成"事实"。

### 2.2 执行：沙箱命令

```bash
# 本地基线（先跑，确认 19 passed, 0 failed）
cd <repo>
python engine/run_demo.py

# 平台沙箱（结构化输出，直接喂给 Agent 回填）
python engine/run_demo.py --json
```

`--json` 输出包含：`classes`（等价类分堆 + 覆盖率）、`verdicts[]`（逐条证书）、`placement`（档内定位）。**结论全部由 `gates.judge()` 生成，本文件只做展示。**

### 2.3 输出：证书 JSON（LLM 不得改写）

每条对照输出一张证书（`Verdict.to_dict()`）：

```json
{
  "subject_id": "USER-001",
  "reference_id": "SM-001b",
  "verdict": "COMPARABLE",
  "blocking_dimension": null,
  "unlock_condition": null,
  "calibration": "calibrated",
  "non_independent": false,
  "gates": {"1": {"gate": 1, "dimension": "substrate", "status": "PASS", "detail": "底物对一致"},
            "3": {"gate": 3, "dimension": "outcome_type", "status": "PASS", "detail": "口径一致：isolated"}},
  "soft_flags": [{"dimension": "base_solvent_temp_time_atmosphere", "level": "L2", "detail": "温度相差 20 °C；溶剂不同：THF vs benzene"}]
}
```

**铁律：** `verdict` 三值 `COMPARABLE / BLOCKED / NEEDS_EVIDENCE` 只来自引擎；LLM 只能把证书翻译成用户文案，**不得自行改写或补一个"我认为"的结论**。

## 4. 平台提示词侧的三条纪律（与 `agents/` 同步，防止 Agent 绕开引擎）

已写入 `agents/A0-orchestrator.md`（三条输出纪律）、`agents/A1-evidence.md`（引用纪律）、`agents/A2-placement.md`（unknown 纪律），并与 `docs/integration/2026-10-27-Agent提示词v3.md`（整段替换版）对齐。平台侧以 v3 为最终提示词，纪律要点：

1. **引用纪律**：先例只能来自知识库 L2 记录；对外用**作者 + 年份 + 期刊卷页 + 表号**（v3 用语规范），`record_id` 只进内部 `retrieval_source` 溯源字段，不进用户可见文案；模型记忆中的文献不得作为先例（演示反例：不得出现 "Lennox & Lloyd-Jones 2014"、"UNIZULU 论文"）。
2. **unknown 纪律**：收率定义未注明 / 口径未决（`outcome_type=unknown`）→ 对外说"需先确认原文"，内部证书为 `NEEDS_EVIDENCE` + 阻断维度 + 解锁条件；禁止表述为确定口径、禁止"不能直接比较"（BLOCKED）。
3. **长度纪律**：默认只输出【结论】/【为什么】/【下一步】四段（≤20 行）；用户说"展开"才给明细；禁止泄漏过程自述与内部判定术语。

> ⚠️ **Skill 注册检查（重要）：** `chemcritic-comparability` 必须在平台 workspace 可被发现。10/27 实测中 21 次 `search_skills` 全部空结果，Agent 被迫退化为"系统提示词里定义角色"。接入后请验证：`search_skills("chemcritic")` 能命中该 Skill。
