## 0. 一句话结论

**不再做"判断实验对不对"的 Agent，改做"给每条文献数值发证书的可比性审计 Agent"。**

- 旧定位：输入一次实验 → 判断是否达标并解释原因 → 必然落到"证据不足"（主演示案例自己就把自己判死了）。
- 新定位：输入一批文献/一次实验 → **逐维判定哪些数字可以并列、哪些绝对不行** → 输出可比性证书 + 被阻断的配对及原因 + 解锁条件 + 一个判别性实验。

**价值锚点从"我猜得准"换成"我不许你假精确"。** 这正是你们 5 天做的工作本身，只是现在把它变成产品。

## 1. 三个候选定位的取舍

| 候选 | 核心承诺 | 创新性 | 6 天可行性 | 判断 |
|---|---|---|---|---|
| **P1 可比性审计官（主推）** | 每个文献数值必须通过 8 维门槛才允许同框比较，否则强制隔离并给出解锁条件 | 高：把"引用可信"从 prompt 约束升级为**结构性生成约束**；可命名、可量化、可被评审追问 | 高：完全复用 SM-001～SM-006 与可比性维度，无需新数据 | **采纳** |
| P2 判别性实验设计师 | 给一次实验，设计能区分候选假设的下一轮实验 | 高：科研味最足 | 中低：依赖化学推理，易退化成"通用建议"清单，6 天难保稳定 | 作为 P1 的收尾模块保留 |
| P3 先例图谱 / 知识图谱 Agent | 把文献建成"底物—条件—结果—口径"图，图上做最近可比邻居检索 | 中：工程感强但概念常见 | 低：需图库与实体对齐，6 天风险最高 | 放弃 |

**为什么不选 P2 单独做：** 它无法避免"建议看起来合理但无法证伪"，而赛题评审明确看"验证方法和结果是否清晰"。
**为什么 P1 能反杀：** 你们之前所有"只能回答证据不足"的输出，在 P1 里从**缺陷变成合法且高价值的结论**——"不可比"本身就是产品要产出的东西。

## 2. 定稿定位：ChemAudit · 文献先例可比性审计

**中文名（备选）：** 可比性审计 / 证据闸门
**英文名（备选）：** ChemAudit（主推）· PrecedentGate · EvidenceLadder
**一句话：** *给每条文献数值发一张可比性证书；没过闸的数字，禁止同框。*

**核心产物「可比性证书」（每一张证书 = 一个 Demo 高光）**

| 字段 | 内容 |
|---|---|
| `record_id` / `locator` | 文献、表/entry/脚注、PDF 页码——必须可点开核验 |
| `value` / `outcome_type` | 原始数值 + 口径（isolated / GC / ¹H NMR / conversion / unknown）。**不做任何换算** |
| `gate_results` | 8 维门槛逐项 PASS / BLOCKED / UNKNOWN |
| `verdict` | COMPARABLE / BLOCKED / NEEDS_EVIDENCE |
| `blocking_dimension` | 卡在哪一维（单一维度优先，便于追问） |
| `unlock_condition` | 补什么证据能升级为可比（如"需作者确认是否 hexadecane 内标"） |
| `peer_block` | 可与哪些记录进入同一对比块；与谁禁止同框 |

**输出三段式（Demo 就按这个顺序演）**

1. **Comparison Block**：唯一允许并列的数字块（通常很小，甚至为空——这本身就是结论）
2. **Blocked Pairs**：被阻断的配对 + 阻断维度 + 解锁条件
3. **Discriminating Experiment**：为区分剩余候选假设，设计的一条最小实验（P2 模块，只出 1 条）

## 3. 机制：8 维门槛（确定性规则，跑在沙箱 Python 里，不由 LLM 决定）

| # | 维度 | 门槛类型 | 判定要点 |
|---|---|---|---|
| 1 | 底物对一致性 | **硬** | 取代基与位置必须一致；芳基碘/氯、烯基/杂芳基默认排除 |
| 2 | 产物/骨架一致性 | **硬** | 目标产物结构一致 |
| 3 | 结果口径 `outcome_type` | **硬** | isolated / GC / ¹H NMR / conversion 必须同类；**禁止任何换算或区间拼接** |
| 4 | Assay 与校准 | **硬** | 内标种类、校准方式、以哪个底物为基准；未注明即 UNKNOWN → BLOCKED |
| 5 | 规模与当量 | 软 | scale mmol、ArX:ArB 当量比、浓度 |
| 6 | 催化体系 | 软 | 催化剂前体 + 配体 + mol% |
| 7 | 碱 / 溶剂 / 温度 / 时间 / 气氛 | 软 | 条件谱系差异要标注等级 |
| 8 | 后处理与纯化路径 | 软 | 直接影响 isolated yield 的可比性 |

**规则：任一硬门槛不过（含 UNKNOWN）→ 禁止进入 Comparison Block。** 软门槛差异只降低证据等级，不阻断，但必须在证书上标出。

**用你们已核验的真实案例验证机制（这是最有力的部分）**

| 案例 | 事实（来自 docs/2026-10-18 与 10-21） | 闸门应输出 |
|---|---|---|
| SM-004 entry1 = 35.0 vs entry7 = 91.9 | 同一篇，催化剂/温度/时间同时不同 | **BLOCKED**（维度 6+7），且不得算两条独立来源 |
| SM-001 = 66% GLC vs 括号 40% isolated | 同一篇，口径不同 | **BLOCKED**（维度 3） |
| SM-006 = 92% GC vs SM-004 = 91.9% GC | 同底物同为 GC，但校准/内标口径未确认 | **BLOCKED**（维度 4 UNKNOWN） |
| 演示输入 35% + 碱/载量/当量缺失 | 多维 UNKNOWN | **NEEDS_EVIDENCE**（维度 4/5/7） |

也就是说：**机制的正确性已经被你们 5 天的核验工作预先验证过了。** 这不是设计出来的故事，是真实数据长出来的。

## 4. SciencePal 核心使用：四件套映射（解决"实质性使用"这一评审维度）

| 平台能力 | 在 ChemAudit 里的角色 | 不可替代性 |
|---|---|---|
| **Personal Knowledge Base** | 上传已核验 PDF（11 篇）与 SM 记录 → 检索时带 locator 定位 | 证据来源就是知识库本身，检索即产品输入 |
| **Isolated Sandbox（Python）** | 跑 8 维门槛校验 + 证书生成，输出确定性 JSON | 规则判定不能由 LLM 口算，否则不可复现 |
| **Agent Co-Building（自建 Agent）** | ChemAudit Agent：编排"检索 → 抽取 → 过闸 → 出证书 → 设计实验" | 产品形态就是平台上的 Agent，不是外挂 |
| **Skills / Skill-Creator** | 把 8 维门槛、Schema、证书模板打包成可导出 Skill | 满足加分项"Agent 配置/工作流导出文件"；可复用、可审计 |
| **Share Link** | 评审点开即看完整执行过程与证书 | 同时解决"链接可访问 + 可复现" |

**红线自查（对照赛题）：** 本方案中 SciencePal 承担的是证据检索 + 代码执行 + 流程编排，**不是写介绍、润色、做 PPT**。这一条必须写进项目说明。

## 5. 可量化评测（评审最缺东西，你们必须有）

**指标：假精确率 FPR（False-Precision Rate）**

> FPR = Agent 允许并列的数值对中，按 gold 标注实际不可比的比例。
> 配套 FNR（漏拒率）= 应可并列却被阻断的比例。

**Gold set（10/25 当天可建）：** 从 SM-001～SM-006 + 34 条候选池中选 **12–15 对**，人工标注 `PASS / BLOCKED + 阻断维度`。评价口径由角色 A 的核验记录直接支撑，不需新调研。

**Baseline 对照（Demo 杀手锏）：**
同一批文献直接丢给通用 LLM，问"该底物的收率范围是多少" → 典型输出 "66%–100%"（把 GC、NMR、isolated、不同催化体系全拼在一起）。
ChemAudit 对同一批数据 → **Comparison Block = 0 对，Blocked Pairs = 12 对，每对给出阻断维度与解锁条件**。

**这一组对照同时拿下三个评审维度：** 科学价值（揭示文献 Agent 的系统性缺陷）、创新性（结构性约束而非提示词）、可行性（可复现、有数字）。

## 8. 风险与应对

| 风险 | 应对 |
|---|---|
| 抽取不稳定（LLM 抽错 entry/脚注） | 只做 3 篇精确抽取，且**抽取结果必须过 schema + 人工 spot-check**；抽不出就输出 UNKNOWN，不许猜 |
| 评审质疑"这不就是文献检索" | 差异点必须一句话说清：**检索回答"有哪些文献"，本产品回答"哪两个数字可以放在一起"** |
| 证书太抽象、Demo 不好看 | 证书用固定卡片模板；先演"通用 LLM 的 66–100%"，再演"ChemAudit 的 0 对可并列" |
| 6 天做不完 | 按第 6 节顺序砍：先砍 baseline 对照 → 再砍展开实验设计 → 保 8 维硬门槛与证书 |
| 报名/链接问题 | 报名已确认；10/30 集中做链接权限体检并留备份录屏 |
