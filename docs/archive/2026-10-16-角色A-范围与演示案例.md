## 一、首期反应类别：锁定 Suzuki–Miyaura 偶联（已核验可行）

**结论：选 Suzuki 偶联，首期范围收敛为「芳基溴 + 芳基硼酸 → 联芳基」。**

选择依据（2026-10-18 核验后修订）：

1. **首期数据可建模**——4-溴苯甲醚 + 苯硼酸有多条确切底物匹配的公开原始研究记录，覆盖 GC、¹H NMR 和分离收率等不同结果口径，适合做来源追溯、条件抽取和可比性判断。
2. **范围可控**——先限定芳基溴 + 芳基硼酸 → 联芳基，可把底物、条件字段和评测边界说清楚；这不等于 Suzuki 全反应域已被覆盖。
3. **需严守证据边界**——现有证据支持“作为首期产品案例可行”，并不足以证明 Suzuki 文献密度在所有候选反应里最高，也不能证明文献条件普遍可比。
4. 具体首批核验记录、选择理由及待补字段见 [2026-10-18 角色 A 首期决策与首批 5 条来源记录](2026-10-18-角色A-Suzuki首期决策与首批5条来源记录.md)。

**简要否决的替代项**：Buchwald–Hartwig（依赖特定膦配体、空气敏感、benchmark 不够教科书级）；Sonogashira（多一个 Cu 助催化剂 + 炔烃操作）；Heck（E/Z 区域选择性让结果判定变复杂）。

## 二、演示案例建议

**主推：4-溴苯甲醚 + 苯硼酸 → 4-甲氧基联苯**（`4-bromoanisole + phenylboronic acid → 4-methoxybiphenyl`）

- 产物有可用于结构确认的 ¹H NMR 特征；结构匹配本身不提供定量纯度。
- 已核验同底物原始先例。例如 Miyaura 1981 报告 66% GC yield，并在括号中报告 40% 分离收率；其他催化体系也报告不同结果。必须保留具体条件和测定口径，不能挑一个数字称为普遍基准。
- 原先引用的 Organometallics 2006 / DOI `10.1021/om0506623` 的 90% 暂不采用：尚未从原文核实对应目标反应，题录信息也需按 DOI 记录复核。

**fallback：溴苯 + 苯硼酸 → 联苯**——被引用最多的 benchmark，先例最多。

**演示叙事（修订）**：优先回放真实文献实验，评测 Agent 能否找回来源、抽取条件并分清结果口径。如保留 `Pd(PPh3)4 / THF / 60℃ / 12h / 35%`，须标记为**模拟输入**，缺失字段标为 unknown；不能预先声称 35% 明显异常或把任一差异条件文献当作同条件对照。

### 现有信息 vs 缺口

| 字段 | 占位现状 | 缺口/问题 |
|---|---|---|
| 芳基卤代物 | 通用 SMILES `"..."` | 未固定底物身份（需定为 4-溴苯甲醚） |
| **碱（种类+当量）** | **完全没有** | **关键缺口**：记录不全时不能判断是否未加碱，也不能把低收率归因于碱；首期 schema 应把缺失标为 `unknown` 并追问 |
| 溶剂体系 | 仅 `THF` | 经典是含水混合溶剂（DME/H₂O、toluene/EtOH/H₂O） |

| 温度/时间 | 60℃ / 12h | 已有，但低于经典回流（~80–100℃） |
| 气氛 | `null` | 缺 N₂/Ar 与否 |
| 规模/浓度 | `null` | 缺 mmol 与溶剂体积 |
| 收率类型 | `yield_pct 35` | 未说明是分离收率还是 NMR/转化率 |
| 纯度测定 | `purity 90` + 仅 `NMR` | 90% 纯度如何定量？常规 NMR 无内标/qNMR 不能严格给出 |
| 完整表征 | 仅 `NMR` | 严谨需 ¹³C、MS/HRMS 或至少 mp + ¹H/¹³C |

## 三、科学判断边界（不能仅凭当前信息推断的结论）

1. **不能先验地称 35% 偏低或异常。** 1981 年确切底物的先例报 66% GC yield / 40% 分离收率；在不知道实验的收率口径时，这些数字也不可直接比较。
2. **不能把 THF / 60℃ / 未记录的碱归为低收率原因。** 从单次观察只能列出候选假设；要下因果结论必须做控制对照实验。
3. **文献收率不是保证目标。** 是可参考范围，不是"换成该条件就必然复现"。
4. **"产物已确认"（结构）≠ "收率/纯度已定量"。** 三个独立主张需要独立证据。
5. **单次对照不足以立论。** 每条排查方向写成"设计能区分假设的下一步验证"，而非"这就是原因"。
6. **不做跨底物泛化。** benchmark 底物最优条件不等价于其他底物。
