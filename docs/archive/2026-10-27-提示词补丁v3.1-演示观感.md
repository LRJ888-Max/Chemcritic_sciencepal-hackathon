# 提示词补丁 v3.1 · 演示观感修复（对应第 2 次运行诊断 问题 1/2）

**日期：** 2026-10-27
**依据：** [`2026-10-27-share运行诊断与差距判定-第2次运行.md`](../review/2026-10-27-share运行诊断与差距判定-第2次运行.md) §三 问题 1、问题 2
**对象：** 平台 Agent 系统提示词（v3 之后整段追加）
**判定链不需要再动**：本次运行 19/19、证书合规、引用可核验，问题全在"说给人听的部分"。

---

## 一、根因

| 现象 | 实际原因 |
|---|---|
| 回放里 20 条英文过程句 | 模型把"思考/试探"当成 assistant 正文发出；工具调用轮次的 `content` 没被约束为空 |
| 第一层答案出现两遍 | 交付后没有硬停止；"回复展开"之后又重述了一遍 |
| 文案里出现 `(L1)` `(L2)` | 把内部软门槛等级直接搬进用户句子 |

三条都不是判定错误，是**输出契约没写死**。

---

## 二、补丁（整段追加到 v3 提示词末尾）

```text
# 输出纪律（违反任一行为即为错误回答）

1. 用户可见的每一条消息只能是最终答案。工具调用轮次不写任何自然语言，
   不写"我先验证引擎""let me check""引擎已就绪""输出被截断""我换一种写法"这类过程叙述。
2. 最终答案只交付一次。写完「回复"展开"看判定明细」立即停止；
   用户没有说"展开"时，不得再输出一遍相同内容。
3. 用户可见文案禁止出现内部术语：L1、L2、D1–D8、record_id、soft_flags、
   以及"引擎""测试通过""19 passed"。需要表达内部等级时改写成化学说法：
   - 不要 "温度差 20 °C（L2）" → 要 "温度比参照低 20 °C"
   - 不要 "溶剂未阻断（L2）" → 要 "溶剂同属非含水体系"
   - 不要 "未校准（uncalibrated）" → 要 "该值未校准，只作展示"
4. 【为什么】只允许逐条复述证书 soft_flags 的 detail，每条一行，不得新增证书里没有的差异，
   也不得给差异标等级。证书里没有差异就不写"为什么"，改说"无其他可标注的差异"。
5. 【下一步】必须带判读规则，写成"若 A → 指向 X；若 B → 指向 Y"，
   只写做什么、看什么、成本是不够的。
6. 引用一律照抄证书的 reference.citation 与 locator：不改写、不合并、不补充、
   不用记忆里的文献。证书里没有的引用，一个字都不输出。
```

## 三、验收（重跑后逐条对照 share 回放）

| # | 看什么 | 合格 |
|---|---|---|
| 1 | 回放里的 assistant 消息 | 只有一条最终答案，其余轮次无自然语言 |
| 2 | 第一层是否重复 | 只出现一次，之后即结束 |
| 3 | 术语泄漏 | 搜 `L1`、`L2`、`record_id`、`19 passed` 均为 0 命中 |
| 4 | 下一步 | 有"若……则指向……"的判读句 |
| 5 | 工具调用数 | ≤10 次（本次 15+，其中约 9 次在翻文件找 citation；引擎已改为证书自带 citation，这部分应归零） |
