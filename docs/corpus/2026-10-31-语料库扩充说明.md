# 语料库扩充说明（2026-10-31）

## 为什么做这件事

ChemCritic 的立身之本是**判定的精确**，而不是库的广度；但"精确"要能兑现，前提是
参照集覆盖面足够，否则用户一问库外底物就只剩 NO_COMPARABLE。本次扩充不动判定层，
先把**参照集候选面**铺开：18 类反应、114 篇文献、194 张数值数据表、1981 行原始数据，
全部带 DOI 与逐字表格，作为后续人工核验入列的候选池，同时如实展示当前覆盖面。

## 采集方式（可复现）

- 来源：NCBI PMC **开放获取子集**（E-utilities esearch + efetch，出版级 XML）。
- 检索：18 类反应各配 1–2 组关键词 + `yield` + `open access[filter]`，按相关度取前若干篇。
- 解析：仅提取出现**数值数据列**（收率/转化率/活性等）的表格，表头、数据行、脚注**逐字保留**；
  同时抓取作者、许可、摘要节选与表格对应的正文句。
- 产物与脚本：

```
scripts/harvest_corpus.py       采集 + 解析（python scripts/harvest_corpus.py --per-class 7）
scripts/enrich_corpus.py        补作者/许可/摘要/上下文句
scripts/make_evidence_cards.py  生成 PDF 证据卡与总目录
data/corpus/2026-10-31.json     语料数据（114 篇，含全部逐字表格）
data/corpus/2026-10-31.md       人读清单
docs/corpus/2026-10-31-语料库目录.pdf   总目录（分布表 + 文献清单）
docs/corpus/cards/PMC*.pdf      每篇一页证据卡（114 张）
```

## 三层证据体系（答辩必讲）

| 层 | 标记 | 数量 | 是否参与判定 |
|---|---|---|---|
| 判定记录 | `A_confirmed` / `candidate` | 44 条（Suzuki） | ✅ 唯一参与 verdict / delta 的层 |
| 语料候选（本次新增） | `imported_unchecked` | 114 篇 / 194 表 / 1981 行 | ❌ 不参与；等待人工核验 |
| 引擎自检 | T1–T28 | 28 项 | — |

**边界声明**：语料候选按检索关键词粗归类（如"不对称氢化"可能命中酶活性表），
表也可能收的是转化率或相对活性而非收率——这正是它停在 `imported_unchecked` 的原因。
纳入判定需三步：逐条人工核验 → 补反应 profile（`profiles.py` 的 PROFILES 表）→ 写入
`data/records.json`。目录规模反映**可扩展面**，不等于已完成的判定覆盖面。

## 与运行包的关系

队友工作台（`ChemCritic_runtime_20261031`）钉住的引擎即本仓库 main 的
`chemcritic-engine/1.4.0`（44 条记录）。本语料库扩充后，`--list-records` 的判定层数量
不变；语料层供展示与核验排期，不改变任何既有判定行为。
